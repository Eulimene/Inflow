# Core 技术契约

本目录集中 Inflow Core 的可读实现契约与 ADR；机器可读 Schema、Policy、Manifest 与证据格式统一存放在 [`文档/机器校验/技术/核心`](../../../机器校验/技术/核心/) 下。总体系统设计见 [`技术设计.md`](../技术设计.md)，产品语义与范围见 [产品文档导航](../../产品/说明.md)，扩展技术契约见 [Extensions 导航](../扩展/说明.md)。

移动文档不改变契约状态或证据状态；各门禁以对应文档中声明为准。

## 文档生命周期与 Recovery

- [`保存与恢复决策记录.md`](./保存与恢复决策记录.md)：保存、Save As、外部修改、自动保存与 Recovery 事务契约。
- [`恢复日志事件模式.json`](../../../机器校验/技术/核心/恢复日志事件模式.json)：Recovery journal 解密后事件的闭集 Schema。

- [`内容净化清单.md`](./内容净化清单.md) 与 [`内容净化证据模式.json`](../../../机器校验/技术/核心/内容净化证据模式.json)：清洗策略、机器 allowlist 与 Release 证据格式。
- [`PDF路径决策记录.md`](./PDF路径决策记录.md)：PDF 生成路径与 postflight 契约。
