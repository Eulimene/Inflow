## 1. 目标

本文定义插件能力、用户入口、授权方式和完整生命周期。所有能力都必须服务用户已表达的写作任务，不得以安装为理由驻留无关入口、广告或后台活动。

## 2. 能力类型

| 类型 | 主要用户价值 | 允许的产品表现 | 不允许的行为 |
| --- | --- | --- | --- |
| 外观与排版 | 适配长文、代码、学术或品牌交付 | 受控视觉参数、预览、明暗变体、可读性说明 | 加载外部内容、隐藏安全提示、改变文档源文 |
| 写作与编辑 | 完成术语、格式、模板和文本转换 | 用户发起的命令、修改预览、单次撤销 | 拦截所有键盘输入、静默改写其他文档、修改保存规则 |
| 诊断与质量 | 发现写作规范、断链、方言或可读性问题 | 只读检查、源位置定位、可忽略规则、修复建议 | 在用户未确认时自动修复，把诊断结果写入源文作为隐藏状态 |
| 领域内容 | 支持学术、工程、流程图等专业表达 | 明确命名的领域块、错误降级、纯文本替代 | 覆盖基础 Markdown 含义，未安装时使文档不可读 |
| 导航与侧栏 | 提供引用、术语、自定义大纲和任务视图 | 用户主动打开的固定区域、明确关闭、回到源位置 | 覆盖编辑区、替换主导航、展示无关广告 |
| 交付与打包 | 生成领域格式、模板或可移植交付物 | 用户主动选择目标、交付前摘要、失败不留残缺结果 | 后台自动发布、未经选择覆盖文件、把导出冒充为保存 |
| 连接器 | 连接用户选择的存储或协作服务 | 明确账号、范围、状态、冲突和退出路径 | 延迟本地保存、扫描未授权文件、静默解决冲突 |
| AI 能力 | 生成、改写、审校、解释或检索写作上下文 | 上下文预览、模型与费用选择、结果差异、显式应用 | 默认上传全文、自动连续执行有副作用操作、静默替换正文 |

人工智能与连接器还必须满足[人工智能与连接器产品规则](./04-人工智能与连接器.md)。

## 3. 插件贡献方式

### 3.1 命令

- 出现在与当前任务相关的命令搜索、菜单或上下文入口中。
- 名称先说结果，不只显示插件品牌。
- 需要读取选区、修改文本或联网时，在执行前显示范围。
- 同一命令失败不影响其他编辑功能，用户可重试或取消。

### 3.2 诊断与建议

- 每条结果包含级别、问题说明、源位置、规则来源和可用动作。
- 用户可忽略单条、单条规则或当前文档范围，并可随时撤销忽略。
- 修复建议必须展示文本差异，支持接受、拒绝和完整撤销。

### 3.3 内容块

- 专有内容使用可读、有命名空间的 Markdown 表达。
- 未安装、停用或渲染失败时，显示原始内容与纯文本说明，不删除源文。
- 内容错误只影响对应块，其他文档结构仍可阅读和导出。

### 3.4 侧栏与工具视图

- 只在用户明确打开时运行，关闭后停止新活动。
- 使用 Inflow 统一的导航、字号、键盘和辅助功能规则。
- 不得隐藏文档保存、冲突或权限提示，不得模仿系统对话框诱导用户。

### 3.5 交付动作

- 展示将使用的文档版本、输出类型、包含的资源与预计结果。
- 目标在用户确认后发生变化时，重新请求确认。
- 完成后明确显示输出位置；失败时不把不完整结果冒充为成功。

## 4. 发现与评估

专业版用户从能力中心查看 Inflow 精选的低风险、单一用途能力；该阶段不提供付费购买或交易。成熟版用户还可从插件市场发现第三方能力及收费能力。两种入口都必须使用下列同一套披露规则，能力中心不得因条目精选而省略权限、数据或退出说明；专业版条目明确显示不收费，成熟版收费条目追加完整费用说明。

用户在安装前必须能看到：

- 插件解决的具体任务和不适用场景。
- 发布者身份、支持渠道、更新日期和兼容范围。
- 必需与可选权限，以及拒绝可选权限后仍可使用的部分。
- 是否读取正文、修改文档、访问工作区、使用网络或产生费用。
- 数据会前往哪个服务、由谁处理、保留多久，以及删除或导出方式。
- 停用或卸载后对文档、设置、本地数据和已产生内容的影响。
- 审核等级、已知风险、异常公告和替代方案。

市场详情页和排名规则见[插件市场与治理](./03-插件市场与治理.md)。

## 5. 安装体验

1. 用户从能力中心或插件市场详情页发起安装。
2. Inflow 显示版本、发布者、必需权限、可选权限、数据去向、费用和高风险提示。
3. 用户可取消，或在不授予可选权限的情况下安装。
4. 安装成功后不自动执行任务，而是展示“如何开始”和当前权限摘要。
5. 首次使用敏感能力时再确认具体文档、工作区、网络或费用范围。
6. 无法安装时说明原因、用户可执行的修复动作，以及是否可保留当前版本。

## 6. 权限体验

### 6.1 权限类别

| 类别 | 范围选项 | 产品要求 |
| --- | --- | --- |
| 读取 | 当前选区 / 当前文档 / 用户选择的工作区 | 优先请求最小范围，工作区读取不能默认扩展到其他文件夹 |
| 修改 | 当前选区 / 当前文档 / 明列的多文件变更 | 执行前展示差异或影响列表，提交后可撤销 |
| 文件操作 | 用户当次选择的文件或目录 | 创建、移动、替换和删除分别说明，不从读取权限推导写入权限 |
| 网络 | 明列的服务与用途 | 首次连接前显示数据类型和目的，新服务或新用途需重新确认 |
| 账号 | 用户选择的单个账号 | 登出或撤权后立即停止新任务，不影响本地文档 |
| 费用 | 单次上限 / 每日上限 / 每月上限 | 执行前展示估算与费用承担方；三项上限的共同生效规则只见人工智能专项设计与附录 A |

### 6.2 授权时长

- **仅本次**：完成当前动作后自动结束。
- **当前文档**：只对该文档有效，文档关闭或用户撤权后结束。
- **当前工作区**：只对用户明确选择的工作区有效。
- **持续允许**：只适用于用户能持续理解的低摩擦能力；仍可在权限中心单项撤销。

拒绝授权时，插件必须说明哪些部分不可用，不反复弹出请求，不把拒绝冒充为故障。

## 7. 日常使用与可见性

- 所有插件入口都显示来源插件，不伪装成 Inflow 内置能力。
- 正在读取整篇文档、处理多文件、联网或计费时，用户可查看当前状态并取消。
- 运行结果明确区分“建议”“已应用”“已交付”“已同步”，不用一个“完成”覆盖不同事实。
- 失败提示包含失败范围、本地文件状态、可否重试和是否可切换替代。

## 8. 更新

用户可在全局选择插件更新偏好，并为单个插件覆盖；选项和初始值只见[附录 B](../07-产品附录/附录B-默认设置.md)。逐插件覆盖必须显示当前来源，并可恢复为跟随全局。

| 变更 | 产品行为 |
| --- | --- |
| 修复与性能改进，权限、数据、费用和兼容边界不变 | 按有效更新偏好提醒或自动安装；自动安装后仍展示摘要和回退影响 |
| 新增读取、写入、网络、账号或费用能力 | 暂停升级，用户阅读变更并重新确认 |
| 减少权限或停止数据收集 | 可正常更新，仍显示改善摘要 |
| 不再兼容当前 Inflow 或文档特性 | 保留现有版本或停用不兼容能力，先说明影响 |
| 安全撤回 | 立即阻止新任务，不允许通过降级重新启用已撤回版本 |

- 自动安装只适用于上表第一类边界不变的更新；无法确认分类时按“提醒并由用户确认”处理。
- 权限、数据去向、费用、兼容范围或发布者主体变化时，任何更新偏好都不能替代重新确认。
- 安全撤回不是普通更新：它始终优先于全局和逐插件偏好，立即阻止新任务，并保留文档、附件与已完成交付物。

## 9. 停用、卸载与数据退出

### 9.1 停用

- 立即停止新任务和自动活动，正在执行的敏感动作被取消或进入可见的安全收尾。
- 插件入口从主界面移除，文档中的源文不修改。
- 用户可在不恢复旧权限的情况下重新启用，敏感能力按需再次授权。

### 9.2 卸载

卸载前显示：

- 将删除的插件设置和本地辅助数据。
- 会保留的用户文档、附件和已交付结果。
- 需要插件才能渲染的领域语法将如何以纯文本显示。
- 是否有可导出的设置、术语、引用或会话数据。

卸载不删除用户正文或标准 Markdown 资源。若插件对外部服务保存数据，详情页与卸载结果都要提供独立的账号数据删除路径。

## 10. 故障与降级

- 单个插件异常时，只停止对应能力，不关闭文档或阻止保存。
- 连续异常时自动停用该插件，告知原因、受影响任务和重新启用条件。
- 缺少依赖、账号、网络或费用额度时，保留可用的本地部分，不循环弹窗。
- 无替代能力时，显示原始 Markdown 和可理解的手动路径。

## 11. 验收标准

1. 未安装任何插件时，用户可完成基础写作、保存、恢复、预览和交付。
2. 专业版启用前可以准确理解提供者、必需权限、可选权限、数据去向和卸载影响；成熟版收费能力还必须理解费用，并达到[附录 A](../07-产品附录/附录A-产品规格与参数.md)对相应阶段的理解率门槛。
3. 拒绝任意可选权限后，其他无关能力仍可用。
4. 所有文本修改均在应用前可见，并可通过一次撤销完整恢复。
5. 权限、数据去向或费用增加时，更新不会在未确认的情况下生效。
6. 停用和卸载后文档源文不丢失，未识别领域内容有纯文本降级。
7. 插件失败、断网、账号失效或停服不会阻止本地保存与关闭。
8. 全局与逐插件更新偏好的来源可见；普通更新按偏好执行，高风险变化仍需重新确认，安全撤回始终优先。
