## 1. 目标

让用户在源码、分栏和即时渲染三种方式之间切换，并始终编辑同一份 Markdown。个人首版（内部验证版）既验证“源码与呈现不分叉”，也验证高频正文能在即时渲染结果中直接修改；复杂结构宁可局部回退源码，也不猜测改写。

## 2. 个人首版（内部验证版）范围

- 三种稳定视图：源码编辑、源码与预览并列的实时预览（分栏）、即时渲染编辑。
- 三种视图共享同一 Markdown 缓冲、修改状态、保存路径和撤销历史，不保存 HTML、富文本或隐藏正文，也不在视图切换时整篇重新序列化。
- 即时渲染编辑在非当前块弱化或隐藏 Markdown 标记，当前块显示完成编辑所需的标记；基础正文可直接编辑，复杂结构聚焦时回退到对应局部 Markdown 源码块。
- 使用现成 CommonMark/GFM 解析能力呈现段落、H1–H6、强调、删除线、引用、无序/有序列表、任务列表、行内代码、围栏代码、表格、链接和图片。
- 仅额外呈现仓库真实使用的 Mermaid `flowchart` 与 `stateDiagram-v2`；其他 Mermaid 保留围栏源码并局部降级。
- 公式、脚注、自定义长期标题标识与 fragment 合同不属于首版。
- 原始 HTML 不执行脚本、样式、导航或网络动作；首版以可读源码或安全转义文本呈现。

## 3. 用户故事与核心流程

### 3.1 边写边看

1. 用户进入分栏预览，左侧编辑 Markdown，右侧展示同一份当前源文本的阅读结果。
2. 输入后预览按实现可承受的节奏更新；更新较慢时不阻塞输入、选择、撤销或保存。
3. 用户可分别滚动两栏。首版不承诺两栏精确同步滚动，但切换到其他视图时保持当前语义块。

### 3.2 即时渲染编辑

1. 用户切换到即时渲染编辑，段落、标题、强调、删除线、行内代码、引用、列表、任务和普通链接文字以阅读结果呈现，并可直接编辑。
2. 用户进入当前块时看到完成编辑所需的 Markdown 标记；围栏代码、表格、Mermaid、图片目标与属性、原始 HTML、复杂嵌套或错误/未知语法只在对应局部显示源码。
3. 用户离开局部源码块后，产品重新尝试安全呈现；失败时继续保留原位源码，不阻断其他内容、源码编辑或手动保存。

### 3.3 处理链接与局部内容

1. 在即时渲染编辑中，用户普通点击链接文字只定位编辑；只有 `Command`+点击才按链接类型执行导航。
2. 对用户明确导航的 `http` 或 `https` 链接，产品交给系统浏览器打开；项目内跳转遵循工作区文档定义的边界。
3. `file`、脚本协议以及其他未明确支持的自定义 scheme 不直接打开，并提供可理解的阻止说明。
4. 本地图片可用时显示图片；缺失时在原位置显示可见占位，不让后续内容错位或消失。

## 4. 功能规则

### 4.1 内容事实与视图

- 源码编辑、实时预览（分栏）和即时渲染编辑共享同一 Markdown 缓冲、修改状态、保存路径和撤销历史；呈现不是第二份文档。
- 预览只使用当前内存中的最新源文本，不借用较旧的已保存文件作为显示事实。
- 视图切换保持同一语义块并保证撤销连续；个人首版不承诺像素级光标、跨块选区或精确滚动位置恢复。
- 独立只读纯预览不属于个人首版，不用隐藏编辑栏的临时布局模拟第四种视图。

### 4.2 即时渲染边界

- 可直接编辑内容及复杂结构的局部源码规则以[编辑与写作](./02-编辑与写作.md)为权威；呈现层不得生成私有富文本或隐藏正文。
- 非当前块只弱化或隐藏当前解析结果能够可靠还原的 Markdown 标记；当前块必须展示完成编辑所需的标记。
- 中文输入法仍有标记文本时不重建当前块；一次用户可理解的修改只形成一次撤销步骤。
- 普通点击链接用于定位可编辑文字，`Command`+点击才导航，避免编辑过程中意外离开文档。
- 解析错误、歧义或未知语法只使当前块原位回退到局部 Markdown 源码；其他块继续呈现，源码编辑和手动保存始终可用。

### 4.3 呈现与降级

- 具体 Markdown 基线、Mermaid 范围和未支持内容的结果只以[附录 F](../07-产品附录/附录F-Markdown方言与定位规则.md)为准。
- 单个 Mermaid 图失败或超出首版范围时，只替换对应图块为源码和局部说明；文档其余内容继续呈现。
- 公式与脚注在首版不获得专用解释；保留用户原文，不因看起来像扩展语法而改写或隐藏。
- 超宽代码、表格和图表在内容区内滚动，不强制撑宽整个窗口。
- 缺失图片显示可见占位和安全的资源名称；不显示完整私密绝对路径。

### 4.4 链接与原始 HTML

- 只有用户明确执行导航才会打开链接；即时渲染编辑中的普通点击不构成导航，文档载入、刷新或视图切换也不能自行导航、打开窗口或下载。
- 首版可点击外部协议白名单只有 `http` 和 `https`。`file`、`javascript`、`data` 及其他自定义 scheme 均不执行。
- 原始 HTML 按不可信内容处理；不执行其中的脚本、样式、表单、事件、嵌入内容、导航或网络请求。
- 图片和 Mermaid 渲染不得引入首版未说明的远程依赖；断网时基础预览仍可使用。

## 5. 后续产品方向

以下能力保留为未来方向，不是个人首版（内部验证版）入口或验收门槛：

- 独立且可持久化的只读纯预览和更多阅读布局；
- 编辑器与预览之间的精确同步滚动、像素级光标、跨块选区和返回位置恢复；
- 无需局部源码回退的表格、代码、Mermaid、图片、原始 HTML 与复杂嵌套可视编辑；
- 公式、脚注、更多 Mermaid 图类及完整扩展语法；
- 自定义长期标题标识、跨文档 fragment 兼容合同；
- 多主题、深色打印一致性、渲染配置、文档健康中心和可定位诊断。

这些能力进入产品时必须继续围绕同一源文本，不得形成隐藏正文或静默改变 Markdown。

## 6. 异常与空状态

- **空文档**：预览区显示克制空状态，不用示例内容冒充用户文档。
- **预览整体失败**：源码编辑仍可用，显示重试入口；不把旧预览冒充当前内容。
- **即时渲染局部失败**：失败块原位显示可编辑源码，其他块继续呈现；不重写或丢弃失败内容。
- **Mermaid 失败或不受支持**：显示围栏源码和局部说明，不阻断其余内容。
- **图片缺失**：在图片位置显示可见占位，保留替代文本和引用，不自动删除或改写源码。
- **链接被阻止**：说明协议不在首版白名单内，可复制链接文本，但不提供绕过执行入口。
- **原始 HTML**：以安全、可读的结果呈现，不出现空白吞掉内容，也不执行其中能力。

## 7. 验收场景

1. 在源码编辑、实时预览（分栏）和即时渲染编辑之间往返切换后，Markdown、修改状态、保存路径和撤销历史一致；同一语义块可继续编辑。
2. 段落、H1–H6、强调、删除线、引用、三类列表、行内代码和普通链接文字可在即时渲染结果中直接编辑；非当前块标记弱化或隐藏，当前块标记足以完成编辑。
3. 围栏代码、表格、图片、原始 HTML、复杂嵌套、错误/未知语法，以及需要编辑的 Mermaid 在聚焦时只展开对应局部源码；失败不影响其他块。
4. 中文输入法标记文本提交前不重建当前块；一次编辑对应一次可理解撤销，不出现重复、丢字或乱序。
5. 仓库现有 `flowchart` 与 `stateDiagram-v2` 样例可呈现；其他 Mermaid 或错误图块保留源码并局部降级。
6. 即时渲染编辑中普通点击链接只定位编辑，`Command`+点击才导航；`http`/`https` 交给系统浏览器，`file`、脚本协议和自定义 scheme 被阻止。
7. 缺失图片显示可见占位；预览失败或更新较慢时，源码编辑、查找、撤销和手动保存仍可继续。
8. 首版不以精确同步滚动、像素级光标/跨块选区恢复或独立只读纯预览作为通过条件。

## 8. 非范围

- 将即时渲染结果保存为与 Markdown 分离的 HTML、富文本或隐藏正文。
- 对文档中的任意脚本、导航、表单、外部资源或自定义协议默认信任。
- 为了视觉一致而将私有标记写入用户 Markdown。
- 把未进入首版的扩展语法显示成已经支持。
