## 1. 目标

让用户一边编辑 Markdown，一边看到同一份当前内容的基础阅读结果。个人首版（内部验证版）优先验证“源码与预览不分叉”，不把沉浸阅读、精准定位或完整专业排版提前变成首版门槛。

## 2. 个人首版（内部验证版）范围

- 两种稳定视图：源码编辑、源码与预览并列的分栏预览。
- 分栏预览中可临时隐藏编辑栏以扩大阅读区域；该状态不是第三种视图，不单独持久化，也不进入最近使用视图记录。
- 使用现成 CommonMark/GFM 解析能力呈现段落、H1–H6、强调、删除线、引用、无序/有序列表、任务列表、行内代码、围栏代码、表格、链接和图片。
- 仅额外呈现仓库真实使用的 Mermaid `flowchart` 与 `stateDiagram-v2`；其他 Mermaid 保留围栏源码并局部降级。
- 公式、脚注、自定义长期标题标识与 fragment 合同不属于首版。
- 原始 HTML 不执行脚本、样式、导航或网络动作；首版以可读源码或安全转义文本呈现。

## 3. 用户故事与核心流程

### 3.1 边写边看

1. 用户进入分栏预览，左侧编辑 Markdown，右侧展示同一份当前源文本的阅读结果。
2. 输入后预览按实现可承受的节奏更新；更新较慢时不阻塞输入、选择、撤销或保存。
3. 用户可分别滚动两栏。首版不承诺按语义块进行精确同步，也不承诺跨视图恢复同一语义位置。

### 3.2 临时扩大阅读区域

1. 用户在分栏预览中临时隐藏编辑栏，预览占用当前内容区域。
2. 用户再次显示编辑栏、执行编辑命令或发起替换时，回到原分栏预览；内容和修改状态不变。
3. 关闭并重新打开文档时，只恢复源码编辑或分栏预览，不恢复“编辑栏已隐藏”这一临时状态。

### 3.3 处理链接与局部内容

1. 用户主动点击 `http` 或 `https` 链接时，产品交给系统浏览器打开。
2. `file`、脚本协议以及其他未明确支持的自定义 scheme 不直接打开，并提供可理解的阻止说明。
3. 本地图片可用时显示图片；缺失时在原位置显示可见占位，不让后续内容错位或消失。

## 4. 功能规则

### 4.1 内容事实与视图

- 源码编辑和分栏预览共享同一 Markdown、修改状态和撤销边界；预览不是第二份文档。
- 预览只使用当前内存中的最新源文本，不借用较旧的已保存文件作为显示事实。
- 临时隐藏编辑栏只改变布局；不创建独立的“纯预览”视图标识、快捷方式语义或持久化状态。
- 首版视图切换只保证内容不变和编辑焦点可重新获得；精确光标、选区、滚动和语义位置连续性后置。

### 4.2 呈现与降级

- 具体 Markdown 基线、Mermaid 范围和未支持内容的结果只以[附录 F](../07-产品附录/附录F-Markdown方言与定位规则.md)为准。
- 单个 Mermaid 图失败或超出首版范围时，只替换对应图块为源码和局部说明；文档其余内容继续呈现。
- 公式与脚注在首版不获得专用解释；保留用户原文，不因看起来像扩展语法而改写或隐藏。
- 超宽代码、表格和图表在内容区内滚动，不强制撑宽整个窗口。
- 缺失图片显示可见占位和安全的资源名称；不显示完整私密绝对路径。

### 4.3 链接与原始 HTML

- 只有用户点击才会打开链接；文档载入或预览刷新不能自行导航、打开窗口或下载。
- 首版可点击外部协议白名单只有 `http` 和 `https`。`file`、`javascript`、`data` 及其他自定义 scheme 均不执行。
- 原始 HTML 按不可信内容处理；不执行其中的脚本、样式、表单、事件、嵌入内容、导航或网络请求。
- 图片和 Mermaid 渲染不得引入首版未说明的远程依赖；断网时基础预览仍可使用。

## 5. 后续产品方向

以下能力保留为未来方向，不是个人首版（内部验证版）入口或验收门槛：

- 独立且可持久化的纯预览、即时渲染编辑和更多阅读布局；
- 编辑器与预览之间的精确语义滚动、标题点击定位、跨视图光标/选区/返回位置恢复；
- 公式、脚注、更多 Mermaid 图类及完整扩展语法；
- 自定义长期标题标识、跨文档 fragment 兼容合同；
- 多主题、深色打印一致性、渲染配置、文档健康中心和可定位诊断。

这些能力进入产品时必须继续围绕同一源文本，不得形成隐藏正文或静默改变 Markdown。

## 6. 异常与空状态

- **空文档**：预览区显示克制空状态，不用示例内容冒充用户文档。
- **预览整体失败**：源码编辑仍可用，显示重试入口；不把旧预览冒充当前内容。
- **Mermaid 失败或不受支持**：显示围栏源码和局部说明，不阻断其余内容。
- **图片缺失**：在图片位置显示可见占位，保留替代文本和引用，不自动删除或改写源码。
- **链接被阻止**：说明协议不在首版白名单内，可复制链接文本，但不提供绕过执行入口。
- **原始 HTML**：以安全、可读的结果呈现，不出现空白吞掉内容，也不执行其中能力。

## 7. 验收场景

1. 在源码编辑与分栏预览之间切换，并临时隐藏/恢复编辑栏后，Markdown、修改状态和撤销历史始终一致；重开文档不恢复临时隐藏状态。
2. 段落、H1–H6、强调、删除线、引用、三类列表、行内/围栏代码、表格、链接和图片使用选定的现成 CommonMark/GFM 解析结果稳定呈现。
3. 仓库现有 `flowchart` 与 `stateDiagram-v2` 样例可呈现；其他 Mermaid 或错误图块保留源码并局部降级。
4. 公式、脚注和原始 HTML 不被执行或猜测性转换，用户原文完整可见。
5. `http`/`https` 只在用户点击后交给系统浏览器；`file`、脚本协议和自定义 scheme 均被阻止。
6. 缺失图片显示可见占位；预览失败或更新较慢时，输入、查找、撤销和保存仍可继续。
7. 首版不以精确语义滚动、跨视图位置恢复或独立纯预览状态作为通过条件。

## 8. 非范围

- 使预览成为与 Markdown 分离的可编辑富文本。
- 对文档中的任意脚本、导航、表单、外部资源或自定义协议默认信任。
- 为了视觉一致而将私有标记写入用户 Markdown。
- 把未进入首版的扩展语法显示成已经支持。
