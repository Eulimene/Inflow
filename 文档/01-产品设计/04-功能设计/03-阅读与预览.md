## 1. 目标

让用户在精确编辑、对照校对、沉浸阅读和低干扰写作之间自由切换，同时保留内容版本、光标、选区和语义位置。预览是对当前 Markdown 的可解释视图，不是另一份文档。

## 2. 范围

- 源码编辑、实时预览、纯预览、即时渲染编辑四种视图。
- Markdown 基础内容、扩展写作内容、代码、表格、任务列表、图片、公式与图表的阅读呈现。
- 源码与预览的标题定位、语义滚动、重名标题定位和返回位置。
- 主题、阅读宽度、可访问性与阅读场景。
- 文档健康中心、渲染配置和可定位诊断。

## 3. 用户故事与核心流程

### 3.1 边写边校对

1. 用户在分栏视图中编辑 Markdown，另一侧展示同一内容的阅读结果。
2. 编辑与预览可独立滚动；启用同步时，预览跟随编辑器附近语义块。
3. 用户主动滚动预览时，同步暂时让路，避免视图争抢。

### 3.2 从阅读回到编辑

1. 用户在预览或大纲中选择标题、诊断或结构块。
2. 产品将对应源文本带到可见区域并保留返回位置，重名标题也能指向正确实例。
3. 当前是纯预览时，产品先进入实时预览，再完成定位。

### 3.3 检查文档质量

1. 用户打开文档健康中心，按结构、链接、资源、语法和交付配置查看问题。
2. 选择问题后定位到对应源文本；对可修复项先预览变更再执行。
3. 用户可对不适用的规则或单条问题选择忽略，且可随时恢复。

## 4. 功能规则

### 4.1 视图连续性

- 四种视图共享同一文档、修改状态和撤销边界。
- 切换视图不改变内容，并尽可能保留光标、选区、滚动与语义位置。
- 即时渲染编辑只在非当前结构中弱化标记；用户进入结构时能看到必要 Markdown，任何操作都可撤销。

### 4.2 呈现与降级

- 支持的 Markdown 版本、公式语法和标题定位只以[附录 F](../07-产品附录/附录F-Markdown方言与定位规则.md)为准；图表类型与产品参数只以[附录 A](../07-产品附录/附录A-产品规格与参数.md)为准。
- 单个公式、图表或其他增强内容失败时，展示局部错误和原内容；当前文档的其他内容不受影响，其他文档仍可阅读与编辑。
- 用户关闭公式或图表呈现后，对应内容以普通文本或代码呈现，不删除源内容。
- 超宽代码、表格和图表在内容区内滚动，不强制撑宽整个窗口。
- 文档进入附录 A 的源码优先级时，实时预览、纯预览、大纲和完整诊断暂停并说明原因；用户仍可使用完整源码、查找、保存、恢复和冲突保护。

### 4.3 主题与配置

- 内置视觉方案围绕长文阅读、代码密集、低照度和高对比等使用场景，以可读性和可访问性为验收依据。
- 主题和阅读宽度只改变呈现，不改变 Markdown。选项与默认值见[附录 B](../07-产品附录/附录B-默认设置.md)，数值范围见[附录 A](../07-产品附录/附录A-产品规格与参数.md)。
- 渲染配置允许用户选择目标阅读环境；预览、诊断和导出对同一配置使用一致语义，切换配置不静默改写源文本。

### 4.4 安全阅读

- 文档不能自行执行脚本、打开窗口、导航或下载。
- 远程内容在用户明确开启前不加载；关闭后预览与导出保持一致占位。
- 原始 HTML 不获得任意脚本或网络能力；未经允许的内容以源文本呈现。

## 5. 异常与空状态

- **空文档**：阅读区显示克制空状态，不用示例内容冒充用户文档。
- **预览整体失败**：编辑仍然可用，提供重试并保留最近可用阅读结果的明确时效说明。
- **局部内容错误**：只替换对应块，展示可定位错误，不阻断其余文档。
- **诊断为空**：说明当前配置下未发现问题，不声称文档在所有目标环境都无问题。
- **远程资源未加载**：显示不泄露完整私密 URL 的占位与用户主动加载入口。

## 6. 验收场景

1. 在四种视图间循环切换后，源文本内容和换行不变，光标、选区和语义位置保持可预期。
2. 重名标题、特殊字符标题和长文档中，从预览、大纲或诊断都能定位到正确源块。
3. 用户手动滚动预览时不被同步立即拉走，恢复同步后回到相近语义位置。
4. 公式或图表中的单个错误不影响当前文档的其他内容，也不影响其他文档；关闭对应呈现后源文本完整保留。
5. 同一渲染配置下，预览、诊断与导出对支持语法、链接和资源不出现无说明差异。
6. 断网时，除用户明确要求的远程资源外，全部阅读、公式、图表与诊断能力可用。

## 7. 非范围

- 使预览成为与 Markdown 分离的可编辑富文本。
- 对文档中的任意脚本、导航、表单或外部资源默认信任。
- 为了视觉一致而将私有标记写入用户 Markdown。
- 在无变更预览的情况下自动修复文档诊断。
