## 1. 目标

让用户既能直接控制可带走的 Markdown，也能在即时渲染结果中完成高频写作。个人首版（内部验证版）以同一份 Markdown 源文本承载三种编辑视图；视觉呈现不能形成隐藏正文，也不能为了所见即所得而猜测性重写复杂结构。

## 2. 个人首版（内部验证版）范围

- 文本输入、选择、复制、剪切、粘贴、撤销、重做与自动换行。
- 当前文档内查找、上一个/下一个结果、替换当前项与全部替换。
- 粗体、斜体、行内代码、一级至六级标题、引用、无序列表、有序列表、任务列表和链接命令。
- 表格只提供插入一份固定空白模板；首版不提供可视化表格编辑或根据选区推断表格结构。
- 三种稳定视图：源码编辑、实时预览（分栏）和即时编辑；三者编辑同一份 Markdown。
- 即时编辑可直接编辑段落、H1–H6、粗体、斜体、删除线、行内代码、引用、无序列表、有序列表、任务列表和普通链接文字。
- 围栏代码、表格、Mermaid、图片目标与属性、原始 HTML、复杂嵌套和未知语法在即时编辑中使用局部 Markdown 源码块完成编辑，不提供猜测性的结构化改写。
- 文本、RTF 与 HTML 载荷只按纯文本粘贴，不把网页或其他应用的富文本样式转换成 Markdown；剪贴板中明确的 PNG/JPEG 位图载荷按图片插入流程处理，不属于富文本转换。
- 支持的解析内容与降级行为只以[附录 F](../07-产品附录/附录F-Markdown方言与定位规则.md)为准。

## 3. 用户故事与核心流程

### 3.1 直接写作

1. 用户打开源码编辑、实时预览（分栏）或即时编辑，在同一份 Markdown 源文本中输入与选择内容。
2. 用户可直接键入任意 Markdown；首版支持的格式命令只处理能够安全识别的当前文本或完整行。
3. 从外部粘贴文本、RTF 或 HTML 时只写入纯文本；剪贴板中的 PNG/JPEG 位图走图片插入流程。每次成功的用户编辑、格式、表格插入或替换操作都形成一次清楚的撤销步骤。

### 3.2 在即时编辑中写作

1. 非当前块以阅读结果呈现，并弱化或隐藏不影响理解的 Markdown 标记；用户把焦点移入一个块时，产品显示完成该块编辑所需的标记。
2. 用户直接修改段落、标题、强调、删除线、行内代码、引用、列表、任务状态或普通链接文字，变化立即落到同一份 Markdown 源文本。
3. 用户聚焦围栏代码、表格、Mermaid、图片、原始 HTML、复杂嵌套或无法安全解释的内容时，只在对应局部显示 Markdown 源码块；离开后重新尝试安全呈现。
4. 当前块解析失败或出现歧义时原位保留局部源码；用户仍可切换到源码编辑并手动保存。

### 3.3 使用基础格式命令

1. 用户选择文本或把插入点放在目标行，再选择一个首版格式命令。
2. 产品能够确定唯一安全结果时执行；遇到跨块、部分标记、代码、链接目标、原始 HTML 或其他歧义结构时保持源码不变。
3. 未执行时不留下半个标记，用户仍可直接编辑源码完成需要的结构。

### 3.4 查找与替换

1. 用户输入查找内容，看到命中数量并在结果间移动。
2. 用户选择替换当前项或全部替换；操作只处理当前文档中实际匹配的文本。
3. 在即时编辑中命中复杂结构时，对应块进入局部源码编辑；该动作不改变当前视图或生成另一份正文。

## 4. 功能规则

### 4.1 编辑事实

- Markdown 源文本是唯一可编辑正文；语法着色、预览和格式入口不产生第二份正文。
- 源码编辑、实时预览（分栏）和即时编辑共享同一 Markdown 缓冲、修改状态、保存路径和撤销历史，不保存 HTML、富文本或隐藏正文，也不因视图切换整篇重新序列化。
- 撤销与重做以文档为边界，不因窗口或布局变化跨文件串联。
- 一次用户可理解的输入、删除、格式或结构操作对应一次撤销；合成输入法的标记文本提交前，不重建当前块或拆成多个不可理解的撤销步骤。
- 三种视图切换时保持同一语义块并延续撤销历史；个人首版不承诺像素级光标位置或跨块选区的精确恢复。
- 文本、RTF 与 HTML 粘贴只插入纯文本，不读取或转换来源中的字体、颜色、HTML、富文本列表或表格样式；PNG/JPEG 位图载荷按资源插入规则处理。
- 重新载入或明确恢复磁盘版本后，旧撤销历史不再可用，避免把已放弃内容恢复回来。

### 4.2 即时编辑规则

| 内容 | 直接编辑行为 |
| --- | --- |
| 段落、H1–H6 | 直接编辑可见文字；当前块显示识别标题层级所需的标记 |
| 粗体、斜体、删除线、行内代码 | 直接编辑可见文字；使用已有基础格式命令时按同一 Markdown 结构修改 |
| 引用、无序/有序/任务列表 | 直接编辑条目文字和首版支持的任务状态；当前块显示维持层级所需的标记 |
| 普通链接文字 | 普通点击只定位编辑；修改显示文字不改写链接目标，`Command`+点击才执行导航 |
| 围栏代码、表格、Mermaid | 阅读时呈现安全结果；聚焦编辑时仅对应块进入局部 Markdown 源码 |
| 图片目标与属性、原始 HTML、复杂嵌套、未知或错误语法 | 不提供结构化改写；原位显示对应局部 Markdown 源码并允许逐字编辑 |

- 非当前块只弱化或隐藏能由当前解析结果可靠还原的 Markdown 标记；用户进入当前块后，完成编辑所需的标记必须可见。
- 局部源码块与视觉块仍映射到同一段 Markdown，不复制内容，也不在离开焦点时对整篇文档重新序列化。
- 解析慢、失败或结果不唯一时优先展示局部源码；不得用旧渲染结果覆盖新输入。
- 项目内 Markdown 跳转与资源访问遵循工作区文档定义的边界；本节只规定即时编辑中的点击手势。

### 4.3 首版格式命令

| 命令 | 首版行为 |
| --- | --- |
| 粗体 | 空选区插入成对标记并把光标置于中间；安全的单段选区用粗体标记包裹；完整同类结构可取消 |
| 斜体 | 空选区插入成对标记并把光标置于中间；安全的单段选区用斜体标记包裹；完整同类结构可取消 |
| 行内代码 | 空选区插入成对反引号；安全的单行选区使用足以包住内容的反引号；不跨行或跨块猜测转换 |
| 一级至六级标题 | 只处理插入点所在行或完整选中的普通文本行；已有其他块结构时保持源码 |
| 引用 | 只对当前完整行或完整选中的普通文本行增加或移除一层引用标记 |
| 无序列表 | 只对当前完整行或完整选中的普通文本行创建或取消无序列表 |
| 有序列表 | 只对当前完整行或完整选中的普通文本行创建或取消有序列表，使用稳定的 `1.` 标记 |
| 任务列表 | 只对当前完整行或完整选中的列表/普通文本行创建或取消任务标记 |
| 链接 | 空选区插入可填写的显示文字和目标；安全的单行选区作为显示文字；已有完整链接可更新目标 |
| 表格 | 在可形成独立块的位置插入固定空白表格模板；不读取选区内容，不在已有表格内执行 |

以上规则不是新的多状态改写矩阵。首版只承诺简单、完整、可识别的情形；任何复杂、部分重叠或结果不唯一的情形都逐字保留源码。

### 4.4 统一保护规则

- 输入法仍有标记文本、文档只读或焦点不在可编辑正文时，修改命令不可用。
- 格式命令不进入行内代码、围栏代码、链接目标或原始 HTML 内部，也不跨越这些结构的边界。
- 多段选区、部分覆盖现有标记、混合块结构或语法不完整时不改写；产品无需判断用户“可能想要”的结果。
- 所有成功修改作为一次文档操作撤销；所有不执行路径保持源文本逐字不变。
- 删除线虽可在即时编辑中直接修改已有内容，但首版不增加删除线命令；围栏代码、图片、表格、Mermaid 和复杂结构只通过源码编辑或局部源码块修改。

### 4.5 查找与替换

- 查找显示匹配数量、当前位置和无结果状态，不因预览是否完成而改变匹配事实。
- 替换当前项只修改当前命中；全部替换作为一次可撤销操作。
- 输入法标记文本尚未提交时不执行替换；只读文档可查找但不可替换。
- 即时编辑中的查找定位到可直接编辑的文字；复杂块命中时只展开对应局部源码，不改变其他块的呈现。
- 首版不承诺跨文档搜索、结果预览面板或基于结构的替换。

## 5. 后续产品方向

以下能力保留为未来方向，不是个人首版（内部验证版）入口或验收门槛：

- 公式、脚注与其他扩展语法的插入或结构化编辑；
- 删除线、围栏代码、图片、Mermaid 与已有表格的专用编辑命令；
- 智能粘贴、括号与围栏辅助、列表自动延续、拼写检查、多光标、行操作和大纲重组；
- 专注模式、打字机模式、行号、字数统计，以及无需局部源码回退的复杂所见即所得编辑；
- 独立只读纯预览、精确跨视图光标/选区恢复和像素级位置同步；
- 覆盖全部选择与嵌套组合的复杂格式状态矩阵。

后续能力进入产品时仍需遵守“源文本唯一、结果可预览、修改可撤销、歧义保留源码”的基础原则。

## 6. 异常与空状态

- **空文档**：编辑区可直接输入；基础格式命令插入最小可填写标记，表格命令插入空白模板。
- **无查找结果**：保留查找词，清楚告知无匹配，不移动光标。
- **格式存在歧义**：不改写源码，不弹出要求用户理解解析器内部状态的复杂对话框。
- **即时渲染解析失败**：只在失败块原位回退到局部源码，不隐藏或替换用户输入；源码编辑和手动保存始终可用。
- **预览更新较慢或失败**：源码输入、选择、查找、撤销和手动保存继续可用。
- **命令不可用**：在只读、输入法标记或非编辑焦点状态下预先置灰，不先执行再报错。

## 7. 验收场景

1. 在源码编辑、实时预览（分栏）和即时编辑之间往返切换后，Markdown 缓冲、修改状态、保存路径和撤销历史一致；同一语义块仍可继续编辑，且不要求像素级光标或跨块选区恢复。
2. 段落、H1–H6、粗体、斜体、删除线、行内代码、引用、三类列表和普通链接文字可在即时编辑中直接修改，保存后磁盘内容仍是普通 Markdown。
3. 围栏代码、表格、Mermaid、图片目标与属性、原始 HTML、复杂嵌套和错误/未知语法在聚焦时只展开对应局部源码；其他块不被重新序列化或改写。
4. 中文输入法组合一段中英文文本期间当前块不被重建；提交后可作为一次可理解操作撤销，正文不重复、不丢失、不乱序。
5. 普通点击即时编辑中的链接文字只定位编辑，`Command`+点击才导航；修改链接文字不改变原目标。
6. 粗体、斜体、行内代码、标题、引用、三类列表和链接命令分别覆盖安全与歧义情形；安全结果可一次撤销，歧义情形逐字保持源码。
7. 表格命令只在独立块位置插入固定空白模板，不消费选区、不修改已有表格，且可一次撤销。
8. 从网页和富文本应用粘贴后只出现纯文本，不带入隐藏 HTML 或来源样式；查找替换在三种视图中保持同一结果。

## 8. 非范围

- 只能在 Inflow 中读取的私有富文本格式。
- 将即时编辑保存为 HTML、富文本或第二份隐藏正文。
- 未经确认或无法撤销的批量源文本重写。
- 在无用户明确操作时执行 HTML、脚本、命令或链接动作。
- 以复杂格式工具替代用户对 Markdown 源码的直接控制。
