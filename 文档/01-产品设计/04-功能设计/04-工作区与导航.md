## 1. 目标

让用户从一份文档平滑扩展到一组长期 Markdown 资产：知道文件在哪里、文档如何组织、如何找到内容，并能在文档、标题、诊断和链接之间往返而不丢失上下文。

## 2. 范围

- 以用户选择的文件夹作为工作区边界。
- 文件树、文件列表、多文档标签页、最近文档和快速打开。
- 当前文档大纲、大纲过滤、标题定位和可撤销的结构重组。
- 工作区全文搜索、结果筛选、快速打开与替换前预览。
- 当前标题、相对文档、跨文档标题、本地附件和外部网页链接。
- 成熟版的跨文档关系、来源说明、演进脉络和质量趋势洞察。

## 3. 用户故事与核心流程

### 3.1 从文件夹开始

1. 用户选择一个已有文件夹作为工作区。
2. 产品展示其文件结构，不要求导入或转换为私有项目。
3. 用户打开多份文档，通过标签页、文件树或快速打开切换。
4. 用户可关闭当前标签页，也可一次关闭整个工作区窗口；任何未保存内容仍进入文档关闭确认。

### 3.2 寻找内容

1. 用户按文件名、标题或最近使用快速打开文档。
2. 需要查找正文时，在工作区范围搜索并按文件、路径或内容类型筛选。
3. 选择结果后打开对应文档、定位命中文本，同时记住来源位置。

### 3.3 沿链接阅读并返回

1. 用户从预览或编辑视图打开当前标题、相对文档或跨文档标题。
2. 当前文档标题直接在原文中定位；首发版打开另一份本地 Markdown 前先说明结果并等待确认。
3. 确认时明确说明内容将作为未命名安全副本打开；用户确认后，Inflow 读取当前已确认的文件内容并以未命名文档打开，打开后保持未命名且不再关联或写回原文件，用户如需保留修改必须另存。
4. 链接含标题片段时，安全副本打开后按[附录 F](../07-产品附录/附录F-Markdown方言与定位规则.md)精确定位；目标不存在或无法确认时不打开。
5. 成长版工作区内的已授权 Markdown 按工作区导航规则打开；前进与后退记录文档、标题和语义位置，返回时不只恢复粗略滚动百分比。

### 3.4 重组长文档

1. 用户在大纲中选择标题及其子结构。
2. 拖动前显示受影响范围，拖动后将完整源文本变更作为单次操作。
3. 用户可一次撤销整个重组。

### 3.5 理解结构与演进

1. 成熟版用户打开结构洞察，在关系视图查看由实际链接、资源引用和来源信息形成的文档关系，并可筛选入链、出链、断链、孤立文档和来源未知项。
2. 用户选择任一关系或问题后，回到对应文件与语义位置；无法确认的关系标记为推断或未知，不冒充用户事实。
3. 演进视图结合本地版本时间线与用户明确提供的来源信息，区分内容编辑历史和外部服务状态，不把二者合并为同一种变化。
4. 质量趋势汇总一段时间内的结构、链接、资源与兼容问题变化，只呈现可解释证据，不给用户或文档打生产力分数，也不自动修改正文。

### 3.6 补充来源并纠正推断

1. 用户在结构洞察中选择文档，查看并新增、修改或删除来源标题、作者或机构、来源位置、日期和备注。
2. 来源信息保存前展示将写入 Markdown 的完整变化；用户确认后与正文修改使用同一保存、冲突和撤销规则，撤销或删除后不留隐藏副本。
3. 用户选择推断关系时可查看证据，并选择“在文档中添加链接”“标记为无关”或“暂时隐藏”；添加链接时，以当前选中的文档为源、推断目标文件或标题为目标，由用户选择插入位置并预览标准 Markdown 相对链接。
4. “标记为无关”和“暂时隐藏”只改变可重置的工作区显示偏好，不改写文档；用户可在隐藏项目中恢复或重新评估。

## 4. 功能规则

### 4.1 工作区边界

- 工作区是文件夹的用户视图，不改变文件夹本身；工作区辅助数据丢失后可从文件重建。
- 未授权的目录不自动扫描。用户首次需要访问工作区外资源时再请求对应范围；拒绝后保留手动授权入口，不反复弹窗。
- 同一文档无论从文件树、链接、搜索或快速打开进入，都回到同一编辑会话。
- “关闭标签页”只离开当前文档视图；“关闭窗口”一次关闭整个工作区窗口。两者都不删除文件或改变工作区目录，未保存文档分别遵循文档关闭规则。

### 4.2 搜索与批量变更

- 搜索结果展示文件、位置和命中上下文，选择后精确定位。
- 跨文档替换在执行前展示全部变更；目标文件发生变化后必须重新确认。
- 批量重命名、移动或结构重组不得留下部分完成且无法识别的状态。

### 4.3 链接与导航

- 使用标准 Markdown 链接，不要求 Inflow 私有链接。
- 当前文档标题在原文内定位。首发版的相对 Markdown 与跨文档 Markdown 链接必须先由用户确认，再以未命名安全副本打开当前已确认的内容；安全副本不持续关联或写回原文件，修改只能由用户另存。
- 标题标识与 fragment 精确匹配只以[附录 F](../07-产品附录/附录F-Markdown方言与定位规则.md)为准；fragment 只解码一次，不重新生成标题标识或猜测目标，重名标题按用户点击的实例定位。
- 网页链接明确离开 Inflow 并使用系统浏览器。危险、未知或无法安全判定的链接不可直接打开。
- 除受支持的本地文档、图片和 PDF 外，其他附件默认只提供在 Finder 中显示；如需交给外部应用，需要本次明确确认。

### 4.4 关系与来源

- 关系视图只使用用户所选工作区内的实际文件、链接、资源引用和明确元数据，不扫描工作区外内容。
- 明确链接、用户声明与产品推断必须使用不同表达；证据不足时显示“未知”，不猜测来源或关系。
- 关系视图是可重建的辅助视图，不成为独立内容事实，也不在用户不知情时写回 Markdown。
- 用户可从每项关系、来源或问题返回实际文件与语义位置；目标缺失时保留原引用并说明缺失原因。
- 用户确认的来源信息必须按[附录 H](../07-产品附录/附录H-来源元数据合同.md)以可见、可编辑、可随文件带走的 YAML Front Matter 保存；保存前展示变化，保存后可撤销，不存入只有 Inflow 能读取的隐藏内容库。
- 推断关系默认只作为带证据的建议；用户预览并确认向当前源文档添加标准 Markdown 链接后，该链接才形成明确关系，不写入专有关系字段。否定或隐藏后可从结构洞察恢复。

### 4.5 演进与质量趋势

- 演进视图以本地版本时间线和用户明确来源信息为依据；缺少基线时不生成虚假趋势。
- 内容编辑历史、迁移记录与外部服务状态分别呈现，不用同步成功替代本地保存事实。
- 质量趋势仅汇总可定位的结构、链接、资源和兼容问题，不评价写作质量、工作效率或个人表现。
- 删除辅助数据后，关系与质量视图可从当前文件重建；历史基线被用户清理后，产品明确说明相应趋势不可恢复。

## 5. 异常与空状态

- **空工作区**：说明当前文件夹没有可显示文档，提供新建文档或更换文件夹。
- **无搜索结果**：保留查询和筛选，提供清除条件，不将空结果误报为索引错误。
- **文件不可访问**：保留标签页与未保存内容，允许重新授权、另存为或关闭。
- **链接目标缺失**：不移动当前位置，给出在 Finder 中查找、重新授权或修复链接的入口。
- **工作区外部变化**：文件树更新不能覆盖已打开文档的本地修改；冲突进入[文档与文件](./01-文档与文件.md)定义的决策流程。
- **洞察暂时过期**：文件刚发生变化时标记“正在更新”，旧结果不能冒充当前事实；用户仍可直接打开实际文件。
- **来源或关系未知**：显示未知原因和可补充的元数据，不自动推断作者、出处或因果关系。
- **历史基线缺失**：说明只能展示当前状态，不能生成变化趋势；不把“无历史”显示成“无变化”。
- **来源信息与外部修改冲突**：停止写入并进入文档冲突流程，不用较新的洞察界面覆盖磁盘内容。

## 6. 验收场景

1. 不导入、不改变文件夹结构即可打开工作区，离开 Inflow 后原文件仍可独立使用。
2. 同一文档从文件树、搜索结果、链接与快速打开进入时，聚焦同一标签页与编辑状态。
3. 全文搜索能从结果定位到正确文档和源文本，空结果与权限不足有不同反馈。
4. 首发版从相对或跨文档 Markdown 链接打开前明确说明将作为未命名安全副本打开；确认后保持未命名且不关联或写回原文件，含标题片段时精确定位。成长版从工作区链接连续导航后，前进和后退都能恢复文档、标题与语义位置。
5. 大纲重组和跨文档批量替换在执行前可检查完整影响，并可以明确撤销。
6. 危险链接、未授权文件和已被替换的本地目标不会被直接打开。
7. 成熟版关系视图中的每项明确关系都能回到实际链接或元数据；推断与未知项不会显示为已确认事实。
8. 成熟版演进与质量趋势能区分内容历史、外部状态和当前问题；历史基线缺失或结果过期时给出准确降级。
9. 新增、修改或删除来源信息前可查看 Markdown 变化，确认后可撤销并随文件带走；推断可查看证据、向当前源文档的指定位置添加标准链接、撤销链接、否定、隐藏和恢复。
10. 多标签工作区可通过可发现命令一次关闭整个窗口，不需要逐个关闭标签页；关闭不会删除文件，未保存内容不会被静默放弃。

## 7. 非范围

- 将工作区转换为只能由 Inflow 读取的项目。
- 未经用户选择扫描整个磁盘或个人主目录。
- 默认把本地附件交给第三方应用执行。
- 云端文件库、团队权限和多人协同作为工作区的内置前提。
- 把关系视图定义为独立知识事实，或在无证据时自动补全关系、来源与因果。
- 对用户、文档或工作节奏生成生产力分数、排行榜或绩效判断。
