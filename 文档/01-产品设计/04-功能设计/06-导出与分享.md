## 1. 目标

让用户确信导出的是自己刚刚检查的那一版文档，且预览、资源、主题、公式、图表与链接在交付物中有可说明的结果。导出不改变 Markdown 文件、保存状态或当前位置。

## 2. 范围

- 面向浏览器阅读的自包含网页交付物。
- 面向归档、打印和固定版式分享的文档交付物。
- 0.1 公共预览版必须交付 PDF；PDF 是 P0 核心交付能力，不是可选预览特性。
- 长图、可移植文档包、无样式或带大纲的网页，以及经产品明确支持的更多单篇格式。
- 系统打印、纸张与边距选择、页眉页脚、元数据与再次导出。
- 专业交付模板的选择、预览、复制为本地模板与退出。
- 具体格式、尺寸、体积、页面和隐私规格只见[附录 A](../07-产品附录/附录A-产品规格与参数.md)。

## 3. 用户故事与核心流程

### 3.1 导出当前文档

1. 用户选择交付格式、渲染配置、主题和可用选项。
2. 产品以当下精确源文本作为本次导出输入，不等待或借用可能落后的预览。
3. 用户选择目标位置；如需替换已有文件，明确确认当时的目标。
4. 产品生成、检查并完成交付；成功后提供在 Finder 中显示或用默认应用打开。

### 3.2 导出前检查

1. 用户可在导出前查看断链、缺失资源、标题结构、方言兼容与远程内容。
2. 问题可定位到源文本；必须修复的阻断项与允许继续的警告分开显示。
3. 用户修改文档后重新导出，新任务使用新版本，已开始的任务仍明确标识其源版本。

### 3.3 打印与再次导出

1. 用户可调整纸张、边距、页眉页脚和分页选项，先预览实际结果。
2. 从可移植文档包或保存的导出配置再次导出时，明确告知当前文档和配置的变化。
3. 打印只在用户主动进入打印流程后使用系统打印选择，导出不自行发送到物理打印机。

### 3.4 使用专业交付模板

1. 用户主动选择附录 A 定义的内置模板，或自己保存的本地模板；初始行为只见附录 B。
2. 产品在应用前展示主题、渲染配置、页面、代码呈现和页眉页脚等交付选项将发生的变化。
3. 用户可继续调整当前版本支持的选项；应用模板只改变本次交付配置，不改写 Markdown。
4. 用户可复制内置模板后保存为本地模板；重命名或删除本地模板不影响 Markdown 和已经完成的交付物。

## 4. 功能规则

### 4.1 源版本与目标

- 每次导出绑定发起时的完整源文本、文档版本和导出配置。
- 导出期间用户继续编辑不会偷偷改变已开始任务；重新导出时明确使用新版本。
- 选择目标后，如产品在最终交付前检测到目标被创建、替换或修改，原覆盖确认失效，必须重新确认或另选位置。
- 首发对目标变化采用尽力检测：开始交付前复核目标，完成后再次检查结果；这不等同于已经排除其他应用在最后交付窗口内同时改写目标。真实目标条件替换与非协作写入者并发证据是正式 1.0 候选阻断，当前保持 `OPEN`。
- 失败或取消不改变 Markdown 和当前编辑。取消只在进入最终替换前生效；写入失败时不推断目标仍是之前的内容，目标最终状态无法确认则要求用户重新检查且不报告成功。

### 4.2 预览与交付一致

- 导出对当前渲染配置、主题、公式、图表、资源和功能开关使用可说明的一致语义。
- 关闭某类增强呈现时，导出与当前预览使用相同降级结果。
- 自包含交付物在断网环境下保留本地内容、样式与受支持的图表公式。

### 4.3 隐私与安全后验

- 交付物不包含可执行脚本、用户的绝对本地路径、不必要的个人元数据或可自行发起的危险动作。
- 图片进入自包含交付物前移除位置与设备类隐私元数据。
- 远程资源未加载时，交付物只保留必要的安全占位，不泄露完整私密地址。
- 交付前检查不通过时不替换最终目标。

### 4.4 0.1 PDF 安全后验

- 安全后验必须检查即将交付给用户的最终 PDF，不以渲染前内容、屏幕预览或中间结果代替。
- 最终 PDF 必须可完整打开，页面数、页面范围、文本、图片和背景与本次交付选择一致；深色主题的背景覆盖完整页面，不留无说明白边或透明页边。
- 最终 PDF 不得包含 JavaScript 或其他可执行脚本、嵌入文件或附件、启动外部程序的动作、访问外部 URI 或网络的动作、本地绝对路径、不必要的作者/设备/软件/位置等隐私元数据，或任何不在本次交付说明中的交互动作。文档内纯导航只能在不扩大这些能力的前提下保留。
- 任一禁止项被发现、PDF 结构不完整、页面结果与本次交付不一致，或检查无法完成时，导出必须失败，不替换最终目标且不显示成功。
- 完整 PDF 安全后验未通过时，0.1 公共预览版不得对外发布；不允许以已知限制、手动抽检或只验证 HTML 作为例外。

### 4.5 模板可解释且可退出

- 模板只是已支持交付选项的命名组合，不包含正文副本，也不成为打开或继续编辑文档的前提。
- 内置模板不可被用户修改覆盖；本地模板的变化只影响之后主动使用它的交付任务。
- 模板含有当前版本不再支持的选项时，应用前列出无法采用的部分，不静默替换为另一套结果。
- 模板不能携带脚本、任意样式、字体文件或联网动作；需要这些内容的模板不可应用。

## 5. 异常与空状态

- **空文档**：可导出明确的空白文档，或在交付物无意义时要求用户确认；不填充示例内容。
- **资源缺失**：区分阻断交付与可以占位的情形，从问题可定位源引用。
- **交付物超出规格**：在写出前停止，给出减少资源、更换格式或调整配置的建议。
- **目标变化**：产品检测到变化时将本次任务暂停在重新确认前；这一结果不宣称排除了尚未检测到的非协作写入竞态。
- **导出失败或取消**：当前 Markdown 和保存状态不变；不把失败表示为成功，目标结果无法确认时要求用户重新检查，可重试或更换位置。
- **模板不可用**：展示缺失或不再支持的选项，允许选择其他模板、仅使用仍受支持的选项或回到未套用模板的交付配置。

## 6. 验收场景

1. 预览尚未跟上最新编辑时立即导出，交付物仍来自发起时的精确源文本。
2. 导出过程中继续编辑，已开始生成的交付物保持原文档版本，新任务使用新文档版本。
3. 用户确认替换后目标发生产品能够检测到的变化，导出暂停并要求重新确认；本场景不作为已经排除最终目标竞态的证明。
4. 断网打开自包含交付物，主题、表格、公式、图表与本地资源结果完整。
5. 深色主题、长文档、超宽内容、分页选项和隐私负例都产生明确结果，不泄露绝对路径或位置元数据。
6. 导出被取消、检查失败或空间不足后，Markdown 和当前编辑保持不变；目标状态无法确认时不报告成功并要求用户重新检查，不推断旧目标必然保留。
7. 应用、调整、复制和删除专业交付模板时，Markdown 与已完成交付物不变；模板的每项影响在应用前可见，不支持项不会被静默替代。
8. 对最终 PDF 执行完整安全后验：结构可打开，页面和背景完整，不含脚本、附件、外部启动或 URI 动作、绝对路径及隐私元数据；任一负例不通过时导出失败且不替换目标。

## 7. 非范围

- 将发布到博客、内容管理系统、代码仓库或图床作为编辑器内置默认能力。
- 依赖用户未配置的外部转换工具才能完成基本导出。
- 将交付物当作当前 Markdown 文件或改变文档保存位置。
- 在无用户操作时自行发送、上传或打印文档。
- 让模板携带正文、任意脚本、任意样式、字体文件或未确认的网络资源。
