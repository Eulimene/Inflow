## 1. 目标

让用户能在不牺牲 Markdown 可迁移性的前提下管理图片和附件。文档移动、另存、资源重命名或导出时，用户应先看到引用影响，再决定是否修改。

## 2. 范围

- 从文件选择、拖放、剪贴板和链接插入图片或附件。
- 新建或复制资源的相对目录、既有外部文件的原位置引用，以及附件命名策略。
- 资源的复制、移动、重命名与 Markdown 引用同步更新。
- 文档移动或另存时的引用影响分析。
- 资源管家：缺失、未引用、重复、远程与超出权限的资源。
- 支持的资源类型及安全打开方式只见[附录 A](../07-产品附录/附录A-产品规格与参数.md)。

## 3. 用户故事与核心流程

### 3.1 插入图片

1. 用户通过文件选择、拖入或剪贴板粘贴图片；各入口接受的类型与保存格式只见附录 A。
2. 剪贴板中的 TIFF 在确认前明确显示将转换为 PNG；取消时不创建资源或引用。
3. 对既有文件，产品按[默认设置](../07-产品附录/附录B-默认设置.md)展示保留原位置或复制到附件目录的结果；对粘贴或新建资源，只展示符合附录 A 位置边界的相对目录。
4. 确认后插入标准 Markdown 引用，操作可撤销；撤销时对新建资源给出明确处理。

### 3.2 移动或重命名资源

1. 用户在资源管家中选择文件并指定新位置或新名称。
2. 执行前展示将被更新的所有 Markdown 引用和无法确认的风险项。
3. 用户确认后作为一次完整操作执行；任何目标在确认后变化时停止并重新分析。

### 3.3 修复资源问题

1. 用户按缺失、未引用、重复或远程分组查看资源。
2. 选择条目后查看引用它的文档和位置，可定位、替换、重新授权或忽略。
3. 批量修复前展示完整变更，修复后可作为单次操作撤销。

## 4. 功能规则

### 4.1 引用可迁移

- 资源引用使用标准 Markdown，不写入只有 Inflow 能理解的标识。
- 相对路径以当前文档位置为基准；文档或资源移动前必须重新计算影响。
- 用户明确选择引用既有外部文件时，不复制或移动原文件；无法形成相对路径时，在确认前说明绝对引用的可移植性影响。
- 任何路径修复都先显示 Markdown 差异，不在后台静默改写。

### 4.2 本地与远程资源

- 本地资源只在用户授权的范围中阅读；权限不足时保留引用并提供手动授权。
- 远程图片在用户明确开启前不请求；用户可将它下载为本地资源并更新引用。
- 资源打开时必须使用刚刚验证的实际文件；如文件在验证后已被替换，不继续打开。

### 4.3 资源变更与删除

- 复制、移动、重命名和引用更新必须形成用户可理解的整体；不能只完成文件移动却留下已知断链。
- 删除被引用资源前展示所有已知影响。未引用不等于可自动删除；用户仍需明确确认。
- 资源清单是可重建辅助信息，不是文件事实。

## 5. 异常与空状态

- **无资源**：资源管家说明当前文档或工作区没有已知资源，提供插入入口。
- **资源缺失**：保留原引用，允许定位新文件、修改路径或忽略。
- **权限不足**：不反复请求；展示影响资源和“重新授权”入口。
- **目标已存在或发生变化**：停止复制或移动，重新展示冲突，不使用过期确认。
- **远程资源失败**：保留占位和原链接，可重试或保持离线，不阻断文档。
- **不支持或可疑文件**：不直接预览或执行，提供 Finder 定位与风险说明。

## 6. 验收场景

1. 文件选择与拖放分别只接受静态 PNG/JPEG；剪贴板 PNG/JPEG 原样进入候选，TIFF 明示转换为 PNG；其他来源安全拒绝。保存、预览与导出只出现静态 PNG/JPEG，整个操作产生标准 Markdown 且可撤销。
2. 文档跨目录另存、资源重命名或移动前，完整展示将改变、不改变和无法访问的引用。
3. 影响确认后任一文件或目标发生变化，原操作不执行并要求重新确认。
4. 资源管家能将缺失、未引用、重复与远程资源分开呈现，从条目可定位到每个引用。
5. 拒绝目录授权后仍可编辑与保存 Markdown，只影响超出权限的资源。
6. 资源在打开前被替换或改变类型时，不打开错误文件。

## 7. 非范围

- 内置图床上传、公开发布或把第三方存储设为必选步骤。
- 默认加载文档中的任意远程内容。
- 自动删除所谓“未引用”文件。
- 将附件嵌入私有容器，导致离开 Inflow 后不可访问。
