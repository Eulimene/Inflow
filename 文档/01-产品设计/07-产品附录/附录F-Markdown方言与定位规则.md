## 1. 目标

为个人首版（内部验证版）给出一份小而可验收的解释基线：明确现成解析器负责什么、Inflow 只额外承担什么，以及不支持内容怎样保留。首版不冻结自定义长期 Markdown 方言，也不为尚未需要的跨工具定位创造专有合同。

## 2. 首版解析基线

### 2.1 基础来源

- 首版采用项目选定的现成 CommonMark/GFM 解析组件，不自行实现完整 Markdown 解析器。
- 候选验证记录实际组件与版本，确保同一候选的预览和 PDF 使用同一解析路径；该组件版本不是当前个人首版（内部验证版）对外冻结的长期兼容承诺。
- “支持 CommonMark/GFM 基础”只表示下表列出的内容已进入首版，不表示完整 CommonMark、完整 GFM 或任意第三方编辑器方言均已通过。

### 2.2 首版支持清单

| 类别 | 首版支持 |
| --- | --- |
| 基础块 | 段落、H1–H6、引用 |
| 强调 | 斜体、粗体、删除线 |
| 列表 | 无序列表、有序列表、任务列表 |
| 代码 | 行内代码、围栏代码 |
| 结构 | GFM 表格 |
| 引用内容 | 链接、图片 |
| Inflow 最小扩展 | Mermaid `flowchart`、Mermaid `stateDiagram-v2` |

软换行、转义、嵌套与歧义文本遵循选定解析组件对上述内容的基础解释。产品不在首版另写一套与组件不同的猜测规则。

### 2.3 原始 HTML

原始 HTML 不获得可执行或增强呈现能力。首版必须把脚本、样式、事件处理器、表单、嵌入对象、导航和网络请求全部视为不可信内容，以可读源码或安全转义文本呈现，不执行也不静默删除用户原文。

## 3. Mermaid 最小扩展

### 3.1 进入首版的图类

只有以 `mermaid` 标记的围栏代码块，且首个有效声明为下列图类时，才进入首版 Mermaid 渲染候选：

- `flowchart`；
- `stateDiagram-v2`。

`graph` 别名、`sequenceDiagram`、`classDiagram`、甘特图、饼图、思维导图及其他 Mermaid 图类均不属于首版。

### 3.2 验收依据

首版只以仓库当前实际样例证明范围：

- `flowchart LR` 的节点、带文字节点、实线箭头、虚线箭头与连线标签；
- `stateDiagram-v2` 的开始/结束状态、普通状态、状态转换与转换标签。

样例中的中文、英文与换行标签按实际仓库内容验证。未在这些样例中使用的子图、交互、脚本、点击动作、外部链接、主题、样式、类成员、复合状态、时序控制和其他 Mermaid 语法不进入首版合同。

### 3.3 安全与失败结果

- Mermaid 只生成离线、静态、无脚本、无网络动作的阅读结果。
- 图类不支持、语法失败或安全结果无法确认时，保留完整围栏源码并显示局部说明；文档其他内容继续呈现。
- 编辑和导出不得为了让图表成功而改写 Mermaid 源码。

## 4. 后置语法

以下内容不是个人首版（内部验证版）解析或交付承诺：

- 行内与块级公式、TeX/LaTeX 命令和公式环境；
- 脚注；
- 除 `flowchart` 与 `stateDiagram-v2` 外的 Mermaid 图类和完整 Mermaid 语法；
- 自定义目录、YAML Front Matter 解释、Alerts、引用与参考文献；
- 任意 CSS、脚本、远程资源或第三方专有扩展。

未支持内容必须保留在 Markdown 源文中。现成解析组件把它视为普通文本或代码时，Inflow 接受该可读降级，但不得标示为已经支持对应扩展。

## 5. 标题与定位边界

### 5.1 首版当前文档定位

- 首版可从解析结果识别 H1–H6，并以标题在当前源文本中的范围和顺序建立临时大纲项。
- 从大纲返回编辑器时，以当前解析结果中的源范围定位；文档变化后重新解析，不把旧范围冒充当前事实。
- 首版不承诺预览与编辑器之间的精确语义滚动，也不承诺跨视图恢复同一光标、选区或滚动位置。

### 5.2 后置兼容合同

个人首版（内部验证版）不冻结以下内容：

- 自定义标题 slug 生成算法；
- 重名标题的长期后缀规则；
- Unicode 规范化、大小写和标点处理版本；
- 当前或跨文档 URL fragment 的精确匹配；
- 与第三方工具 slug 规则的兼容或迁移。

解析组件为页面内部实现生成的临时标识不得被记录为 Inflow 长期内容合同。需要跨文档 fragment 或公开兼容时，必须另行定义、版本化并增加迁移与反向样例。

## 6. 链接协议边界

- Markdown 链接的显示文字按基础解析结果呈现。
- 只有用户点击才可触发外部动作；文档打开、预览刷新和 PDF 生成不得自行导航。
- 个人首版（内部验证版）可执行外部协议白名单只有 `http` 与 `https`。
- `file`、`javascript`、`data` 和其他自定义 scheme 保留可见文字，但不生成可执行动作。
- 图片引用与链接目标不得把用户绝对本地路径写入最终 PDF。

## 7. 一致性与演进

- 源码、分栏预览和基础 PDF 对本文首版支持清单使用同一解析路径与同一安全降级。
- 未支持内容优先保留原文，不为视觉相似进行不可逆改写。
- 后续增加公式、脚注、Mermaid 图类或定位合同时，必须明确进入版本、旧内容结果、失败降级和验收样例。
- 面向外部用户冻结长期方言前，应先选择并记录解析组件升级策略；个人首版（内部验证版）不提前作出该承诺。

## 8. 验收场景

1. 段落、H1–H6、强调、删除线、引用、三类列表、行内/围栏代码、表格、链接和图片分别有正常与错误样例，预览和 PDF 结果一致或使用本文规定的可读降级。
2. 仓库当前所有 `flowchart` 与 `stateDiagram-v2` 围栏样例可以离线呈现为静态结果。
3. 其他 Mermaid 图类、错误 Mermaid、公式与脚注保持完整源码，不影响文档其余内容，也不显示为首版已支持。
4. 原始 HTML 的脚本、样式、事件、表单、嵌入、导航和网络样例均不执行，原文仍可读。
5. `http`/`https` 只在用户点击后打开；`file`、脚本协议和自定义 scheme 在预览与 PDF 中均不可执行。
6. 当前文档大纲可以按最新 H1–H6 源范围返回编辑器；自定义 slug、精确 fragment 与跨视图语义位置不作为首版通过条件。
7. 验收记录包含实际 CommonMark/GFM 组件与版本、仓库 Mermaid 样例标识及结果，不用一个理想样例宣称完整方言兼容。

## 9. 非范围

- 宣称兼容完整 CommonMark、完整 GFM、完整 TeX、完整 Mermaid 或某个第三方编辑器方言。
- 用实现组件名称代替用户可理解的支持清单。
- 在个人首版（内部验证版）中冻结长期 slug、fragment 或跨工具定位规则。
- 对不支持内容执行、隐藏、删除或猜测性转换。
