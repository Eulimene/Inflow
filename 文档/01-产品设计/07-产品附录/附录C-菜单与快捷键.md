## 1. 目标

让所有核心操作既可通过菜单发现，又可通过符合 macOS 习惯的快捷键高效执行。快捷键在编辑器聚焦时仍应执行命令，不得意外输入字符。

## 2. 范围

- 应用、文件、编辑、格式、插入、显示、导航、工具、窗口和帮助菜单。
- 已冻结默认快捷键与未分配命令。
- 不同聚焦、文档状态与视图下的命令可用性。
- VoiceOver 名称、键盘可达与菜单发现性。

## 3. 用户故事与使用流程

1. 新用户从菜单查找操作，在菜单项右侧看到快捷键。
2. 熟练用户在文本输入中直接执行快捷键，光标与输入法不会吞掉命令或留下多余文字。
3. 命令在当前情境不可用时，菜单项置灰且保留可识别名称，不用执行后报错代替预先反馈。

## 4. 功能规则与命令表

### 4.1.1 macOS 与拖放入口

| 入口或手势 | 结果 |
| --- | --- |
| Finder > 打开方式 > Inflow；或 Inflow 已是该扩展名默认应用时的 Finder > 打开/双击 | 打开所选 `.md` / `.markdown`；是否设为默认应用只由用户在 macOS 中决定 |
| 拖放 `.md` / `.markdown` 到 Dock 中或 Finder 中的 Inflow 应用图标 | 按“文件 > 打开…”处理 |
| 拖放文件夹到 Dock 中或 Finder 中的 Inflow 应用图标 | 按“文件 > 打开项目…”处理 |
| 拖放静态 PNG/JPEG 到编辑区 | 按“插入 > 图片…”处理；未命名文档先完成首次保存 |
| 拖放外部文件或文件夹到项目目录树 | 不执行复制、移动、导入或整理；项目树只接受当前项目内的选择和项目内新建命令 |

外部目标无论在 Inflow 冷启动还是已运行时到达，都只处理目标；冷启动不额外创建空白文档。应用先规范化目标并与已打开文件或项目去重，重复目标只聚焦现有窗口，不消耗可复用空白窗口。最多一份未改动的空白未命名窗口可承接第一个尚未打开的目标；已有输入或其他修改时必须保留并另开目标窗口。一次收到多个 Markdown 时，其余新目标分别新建窗口。

### 4.7 命令一致性规则

- 所有快捷键命令必须有可发现的菜单项；视图中的按钮不能成为唯一入口。
- 文本编辑器聚焦时，命令快捷键优先执行命令，不向正文输入字符。
- 输入法候选期间，不得把候选确认误作文档命令。
- 输入法仍有标记文本时，即时渲染编辑不得重建当前块；提交后的单次用户编辑形成一次可理解撤销。
- 菜单项状态与当前文档、选区、视图和权限一致；不可用时置灰，不隐藏核心命令。
- 格式与插入命令只处理[编辑与写作](../04-功能设计/02-编辑与写作.md)明列的简单情境；嵌套、混合或不确定时保持源码不变。
- 即时渲染编辑中普通点击链接只定位编辑，`Command`+点击才执行导航；该手势不另占用菜单快捷键。
- 源码编辑、实时预览与即时渲染编辑切换后共享当前文档的修改状态、保存路径和撤销历史。
- 项目内“新建 Markdown 文件…”只由项目侧栏按钮或右键菜单发起；无目录树选择时按钮以项目根目录为目标。用户确认文件名后立即在磁盘创建并打开，当前项目文档有未保存更改时先处理“保存 / 不保存 / 取消”；磁盘创建成功但打开失败时保留文件与树节点。
- 未分配命令不能临时借用可能冲突的系统或编辑快捷键。

## 5. 异常与空状态

- 无文档时，保存、导出、格式和文档视图命令置灰；新建、打开和设置仍可用。
- 文档只读时，阅读、复制、查找、导出和另存为可用，修改性命令置灰。
- 即时渲染编辑中查找命中复杂结构时，只展开对应局部 Markdown 源码块并保持当前视图。
- 快捷键与系统、输入法或可访问性命令冲突时，保留系统语义，该产品命令暂不分配。

## 6. 验收场景

1. 个人首版上表命令在源码编辑、查找框、实时预览和即时渲染编辑聚焦时执行正确命令或保持明确不可用。
2. 执行命令后源文本不出现快捷键字符或多余输入。
3. 菜单项、快捷键、工具栏和 VoiceOver 名称指向同一操作语义。
4. 无文档、只读文档和未命名文档下的菜单可用性符合规则。
5. `⌘1`、`⌘2`、`⌘3` 分别切换源码编辑、实时预览和即时渲染编辑，且视图切换不重置撤销历史。
6. 新建独立文档、打开文件、打开项目、项目内新建 Markdown、刷新项目、显示项目侧栏、编辑、查找、手动保存、切换三种视图和导出 PDF 均有可发现入口。
7. Finder、“打开方式”、默认应用以及 Dock/Finder 中 Inflow 应用图标的拖放均复用相同的打开、聚焦与窗口保护规则；编辑区图片拖放不会被误判为打开文档。

## 7. 非范围

- 为未冻结命令抢占系统保留或常用输入法快捷键。
- 为独立只读纯预览分配个人首版菜单或快捷键。
- 仅出现在上下文菜单、隐藏手势或工具栏中的核心命令。
- 用不可发现的快捷键代替清晰的功能信息架构。
