## 1. 目标

在保存、恢复、冲突、权限、预览、资源和导出等关键时刻，使用稳定、直接、不掩盖后果的文案。用户应在操作前知道什么会被保留、什么会被替换、哪些选择可逆。

## 2. 范围

- 标题栏与非模态状态。
- 关闭、保存、另存为、恢复与外部变更提示。
- 编码、换行、权限、链接与资源错误。
- 预览、公式、图表、诊断与导出错误。
- 设置保存与恢复默认提示。
- 插件安装、授权、更新、停用、卸载与安全撤回状态。
- 插件市场、人工智能任务、连接器同步、费用与数据清理提示。

## 3. 用户故事与使用流程

1. 用户看到提示标题后，不需要了解内部原因也能知道当前状态。
2. 说明先回答“发生了什么”与“你的内容是否安全”，再给出恢复方式。
3. 按钮按建议操作、替代操作、取消或危险操作的逻辑排列；不可逆操作需要二次确认。
4. 操作完成后提示只说明真实结果，不把恢复保护说成已保存，不把占位说成已导出。

## 4. 功能规则与权威文案

### 4.1 持续状态

| 状态 | 显示文案 | 显示规则 |
| --- | --- | --- |
| 有未保存更改 | 使用系统窗口修改标记，无额外文字 | 直到成功保存或用户明确放弃 |
| 保存中 | “正在保存…” | 短暂非模态；不阻断继续编辑 |
| 已保存 | 移除窗口修改标记 | 只在目标复核与本次精确内容一致、且系统文档状态一致时进入；不持续显示“已保存”强提示 |
| 只读 | “只读” | 文件不可写时显示；复制、另存为可用 |
| 自动保存已暂停 | “自动保存已暂停” | 目标缺失、不可写或存在冲突时显示 |
| 恢复保护降级 | “恢复保护暂时不可用” | 不禁止手动保存；直到保护恢复 |

## 5. 异常与空状态

- 动态占位符无值时不显示未替换的 `{name}`；改用不依赖该值的备用句子。
- 无可恢复文档时，恢复中心显示“没有可恢复的文档”与“完成的保存不会出现在这里。”
- 无诊断问题时，文档健康中心显示“在当前配置下未发现问题”，不声称在所有目标中都完全正确。
- 同时发生多个问题时，优先呈现数据丢失或覆盖风险，其余问题收纳到可展开详情，不连续叠加弹窗。

## 6. 验收场景

1. 每个危险操作都明确说明会放弃、替换或删除什么，且提供取消；首发文件冲突没有覆盖磁盘入口。
2. 保存、恢复、冲突、另存为、编码、权限、预览、资源、导出和设置的正向、失败与取消场景均能对应到本附录的唯一文案。
3. “已保存”只在用户文件确已成功保存时表达；恢复保护、预览和导出不误用该词。
4. 按钮顺序、默认聚焦和语气符合破坏性程度，键盘与 VoiceOver 可完整读取。
5. 在窄窗口、长文件名、中英文混排和占位值缺失情况下，文案仍可理解且不截断关键后果。
6. 首个公开市场的发布者身份、版本审核、主体转移、退出和撤回状态均说明责任主体与下一步；评价、购买、续费、退费和恢复购买文案只在后续商业市场进入。
7. 连接器断开会说明撤权结果；待完成或外部结果未知的记录不能被“删除设置”静默清除，并有可理解的保留原因与核对路径。
8. 首次付费人工智能任务在三项上限未设置、提供方不能权威约束最高费用或额度不足时使用独立阻断文案；首版结果只提供复制纯文本建议。

## 7. 非范围

- 内部错误码、日志文本、调试标识或实现组件名称。
- 营销文案、帮助中心长文或引导教程。
- 用模糊的“保留当前内容”代替保存副本或重新载入等明确后果。
