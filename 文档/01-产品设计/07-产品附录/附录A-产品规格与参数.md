## 1. 目标

为全部产品文档提供唯一的精确规格来源。功能文档只说明为什么和如何使用，不重复本附录中的数值、范围、格式清单或保留周期。

## 2. 范围

- 平台、文件、编码和换行规格。
- 编辑、预览、分栏和内容支持范围。
- 响应时间、基准文档与恢复保留参数。
- 图片、链接、导出格式、页面与体积边界。
- 可配置项的初始值不在本文重复，统一见[附录 B](./附录B-默认设置.md)；文件与交付格式的固定基准仍由本附录定义。

## 3. 用户故事与使用流程

- 作为用户，我希望在选择文件、调整字号、导出或等待恢复时，看到稳定、不相互矛盾的产品边界。
- 作为产品与设计人员，我在功能稿中遇到数值或支持清单时，必须引用本附录，而不是创建第二个版本。
- 规格变更时，先在本附录完成产品评审，再检查所有引用文档的用户语义是否需要同步调整。

## 4. 功能规则与权威规格

### 4.1 平台与文件

| 规格项 | 产品规格 |
| --- | --- |
| 支持系统 | macOS 14 Sonoma 或更高版本 |
| 支持处理器 | Apple Silicon；不支持 Intel 或 Rosetta 作为正式路径 |
| Markdown 文件扩展名 | `.md`、`.markdown` |
| 可直接编辑编码 | UTF-8、UTF-8 BOM |
| 新文档编码 | UTF-8，无 BOM |
| 新文档换行 | LF |
| 已有文档保存 | 保留原 BOM 状态与主换行风格（LF 或 CRLF） |
| 混合换行 | 编辑前一次性请用户选择 LF 或 CRLF；未选择时只读且不自动写回 |
| 不支持编码 | 不猜测、不进入文本编辑、不覆盖原文件 |

### 4.2 编辑与 Markdown 内容

| 规格项 | 产品规格 |
| --- | --- |
| 编辑器字号 | 12–28 pt |
| 编辑器行高 | 1.2–2.0 倍 |
| 标题 | H1–H6 |
| 基础语法 | 段落、粗体、斜体、删除线、链接、自动链接、引用、有序/无序/嵌套列表、任务列表、行内/围栏代码、表格、分隔线、图片 |
| 首发增强写作内容 | 脚注 |
| 专业版增强写作内容 | 目录、YAML Front Matter、Alerts；未启用对应能力时保留原文 |
| 代码围栏 | 至少 3 个反引号；选区包含更长连续反引号时，围栏长度为最长连续长度加 1 |
| 内置表格插入模板 | 3 列 × 3 行，包含 1 行表头与 2 行数据；插入后选中第一个表头单元格 |
| 公式 | `$...$` 行内公式、`$$...$$` 块级公式；块级起止定界符各自独占一行 |
| 公式排除区域 | 代码、行内代码、围栏代码、链接目标与原始 HTML 内不解析公式 |
| 图表基本类型 | 流程图、时序图、类图、状态图 |
| 字数 | 中日韩文字每个计为一字；连续拉丁字母或数字按由空白和标点分隔的词计数；空白与标点不计入字数 |
| 字符数 | 按用户可见字符计数；分别提供“含空格”与“不含空格”，换行不计入 |

### 4.2.1 专业版表达规格

| 规格项 | 产品规格 |
| --- | --- |
| 公式增强 | 多行对齐、公式编号、文内引用，以及 `aligned`、`align`、`gather`、`cases`、`matrix`、`pmatrix`、`bmatrix` 环境；不支持时保留原始公式并定位问题 |
| 图表增强 | 在基本类型外支持实体关系、甘特、饼图、思维导图和时间线；单类失败不影响其他内容 |
| 引用与参考文献 | 支持引用键、作者—年份式与数字式呈现、参考文献列表、缺失来源检查，以及 APA 第 7 版（作者—年份）、Chicago 第 17 版（作者—年份）、IEEE（数字）和 GB/T 7714—2015（数字）四种样式；Markdown 脚注属于首发增强写作内容，不作为参考文献样式 |
| 专业代码呈现 | 语言标识、行号、重点行、长行处理和复制；所有选项只改变呈现与交付物 |
| 领域表达 | 由用户主动启用的单一用途能力提供；停用或缺失时保留原始 Markdown 与可读说明 |

### 4.2.2 渲染配置

| 配置 | 生效版本 | 支持边界 |
| --- | --- | --- |
| Inflow 标准 | 首发版 | 使用当前版本全部已支持的 Markdown、公式、图表、资源与专业表达 |
| 通用 Markdown | 专业版 | 仅使用段落、标题、强调、链接、图片、引用、列表与代码等通用结构；扩展内容保留原文并列为兼容提示 |
| 代码托管平台 | 专业版 | 在通用结构上增加表格、任务列表、删除线、自动链接与脚注；其他增强内容保留原文并列为兼容提示 |
| 学术交付 | 专业版 | 在通用结构上增加脚注、公式、引用与参考文献；图表和其他领域内容按当前支持情况明确降级 |

配置只改变预览、诊断和交付解释，不自动改写 Markdown。默认配置见附录 B。

### 4.4 保存、恢复与历史

| 规格项 | 产品规格 |
| --- | --- |

| 恢复保护最长间隔 | 5 秒 |
| 恢复内容 | 源文本、原路径、光标、选区、显示视图、滚动位置与最后更新时间 |

### 4.5 链接与资源

| 规格项 | 产品规格 |
| --- | --- |
| 应用内导航 | 当前文档标题、相对 Markdown、跨文档标题 |
| 可直接预览的本地图片 | 静态 PNG、JPEG |
| 可受控打开的本地类型 | Markdown、静态 PNG/JPEG、PDF |
| 其他附件 | 默认只在 Finder 中显示；交给外部应用前需要当次明确确认 |
| 远程图片 | 成长版起：用户明确开启后可受控加载；可下载为本地资源 |
| 不支持的本地预览 | SVG、动画图片、类型与内容不一致的文件；显示占位或 Finder 定位 |
| 新建或复制的附件位置 | 必须位于当前文档同级目录或用户选择的工作区相对目录，不进入 Inflow 私有位置；具体选项与默认见附录 B |
| 引用既有外部文件 | 用户可明确选择保留原位置；能形成相对路径时优先使用相对路径，否则保留绝对引用并在确认前提示可移植性影响；该选择不复制或移动原文件 |
| 附件命名 | 选择已有文件时保留原名；重名时在写入前让用户选择替换、保留原位置或使用递增后缀；剪贴板图片使用 `image-001` 起的递增名称 |
| 未命名文档资源 | 在首次保存时连同目标目录与引用影响一起确认；取消保存时不在用户目录留下未确认附件 |

| 规格项 | 产品规格 |
| --- | --- |
| 生效版本 | 成熟版 |
| 关系分类 | 入链、出链、断链、孤立文档、明确链接关系、推断关系、来源未知 |
| 来源信息字段 | 来源标题、作者或机构、来源链接或文件、发布日期或获取日期、备注；各字段均可单独留空或删除 |
| 质量趋势时间范围 | 最近 7 天、30 天、90 天或全部可用历史；默认见附录 B |

| 推断处置 | 查看证据、在当前源文档的用户选择位置添加指向目标文件或标题的标准 Markdown 相对链接、标记为无关、暂时隐藏、恢复隐藏项目 |

推断本身不是关系事实。只有用户预览并确认标准 Markdown 链接后，才按该链接形成明确关系；不写入专有关系字段。

### 4.6 迁移来源

| 规格项 | 产品规格 |
| --- | --- |
| 生效版本 | 专业版 |
| 直接来源 | 单个 `.md` / `.markdown` 文件，或用户选择的现有文件夹 |
| 直接来源容量 | 单个文件不超过 500 MiB；现有文件夹按实际内容计算，总容量不超过 10 GiB、最多 20,000 个条目、目录最深 20 级、单个条目不超过 500 MiB |
| 迁移包格式 | 标准 `.zip`；内容由 Markdown、普通文件夹和关联资源组成，不要求 Inflow 私有清单或来源产品版本 |
| 迁移包容量 | 压缩包不超过 2 GiB，展开后不超过 10 GiB，最多 20,000 个条目，目录最深 20 级，单个条目不超过 500 MiB |
| 来源内容边界 | 直接文件夹或迁移包中的嵌套压缩包、可执行内容和无法识别的私有资料库只列为不支持，不运行、不继续展开、不猜测转换 |
| 来源版本 | 按实际内容预检，不承诺某个第三方产品版本“完全兼容”；每次迁移都展示逐项结果 |

| 交付类型 | 生效版本 | 产品规格 |

| 模板边界 | 专业版 | 应用前展示将改变的交付选项；内置模板不可被覆盖，用户可复制后调整为本地模板；本地模板可重命名和删除，不包含脚本、任意样式、字体文件、网络资源或正文副本 |
| 交付隐私 | 首发版及后续 | 不包含绝对本地路径、可执行脚本、不必要个人元数据、位置与设备类图片元数据 |

## 6. 验收场景

1. 全库搜索精确数值、默认值、快捷键和状态文案时，分别只能在对应附录找到权威定义。
