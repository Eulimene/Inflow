## 1. 目标

为全部产品文档提供唯一的精确规格来源。功能文档只说明为什么和如何使用，不重复本附录中的数值、范围、格式清单或保留周期。

## 2. 范围

- 平台、文件、编码和换行规格。
- 编辑、预览、分栏和内容支持范围。
- 响应时间、基准文档与恢复保留参数。
- 图片、链接、导出格式、页面与体积边界。
- 可配置项的初始值不在本文重复，统一见[附录 B](./附录B-默认设置.md)；文件与交付格式的固定基准仍由本附录定义。

## 3. 用户故事与使用流程

- 作为用户，我希望在选择文件、调整字号、导出或等待恢复时，看到稳定、不相互矛盾的产品边界。
- 作为产品与设计人员，我在功能稿中遇到数值或支持清单时，必须引用本附录，而不是创建第二个版本。
- 规格变更时，先在本附录完成产品评审，再检查所有引用文档的用户语义是否需要同步调整。

| 规格项 | 产品规格 |

| 公开平台范围 | 未冻结；在个人验证通过并进入公开预览决策时另行定义，不由当前内部版本推导 |

| 可直接编辑编码 | UTF-8、UTF-8 BOM |

| 个人首版基础结构 | 段落、H1–H6、强调、删除线、引用、有序/无序/任务列表、行内/围栏代码、表格、链接和图片 |

### 4.4 保存、恢复与历史

| 规格项 | 产品规格 |
| --- | --- |
| 自动保存 | 个人首版不提供；用户使用 `⌘S` 手动保存，关闭有修改的文档时使用系统式保存确认 |
| 保存完成判定 | 使用 macOS 标准文档保存流程（底层由 AppKit 文档框架提供）的结果；失败时保持当前编辑和修改标记，不把恢复快照表示为已保存 |
| 外部变化 | 检测到后显示“重新加载”；有未保存内容时在放弃前确认，未处理变化时保存到原路径需要一次明确覆盖确认；不提供三版本比较或自动合并 |
| 轻量恢复快照 | 每个打开文档只保留一个最新快照；异常退出后可“恢复为未命名文档”或“放弃”，恢复不会自动写回原路径 |
| 恢复范围 | 保存源文本及恢复所需的最小关联信息；不提供恢复中心、批量恢复、独立版本时间线、密钥生命周期或容量管理界面 |
| 恢复失败 | 不得阻止用户手动保存当前 Markdown；无法读取的快照不冒充可恢复内容 |
| 本地版本时间线保留范围 | 成长版起：1–365 天、100 MiB–5 GiB；同时设置时以先达到者为准，用户可关闭 |
| 最近文档 | 个人首版可使用 macOS 提供的“打开最近”能力，但不作为个人首版通过门槛；完整容量和授权管理后置 |

### 4.5 链接与资源

| 规格项 | 产品规格 |
| --- | --- |
| 当前文档标题导航 | 在当前原文内精确定位，不创建第二份正文 |
| 个人首版本地 Markdown 链接 | 按普通可编辑文档打开原文件；同一路径已经打开时聚焦现有窗口，外部变化沿用普通文档提示 |
| 本地 Markdown 标题片段 | 使用当前解析器生成的标题定位结果；个人首版不冻结跨版本 slug 兼容合同 |
| 成长版工作区导航 | 相对 Markdown 与跨文档标题按工作区导航、单一会话及历史规则打开 |
| 可直接预览的本地图片 | 静态 PNG、JPEG |
| 图片文件选择与拖放 | 只接受内容确认为静态 PNG 或 JPEG 的文件；扩展名与内容不一致或其他类型不进入候选 |
| 图片剪贴板 | 个人首版只接受 PNG/JPEG；TIFF、SVG、动画图片与未知类型后置或拒绝 |
| 图片保存、预览与导出 | 只使用静态 PNG/JPEG |
| PNG/JPEG/PDF 链接 | 读取为应用管理的只读临时副本，再交给系统默认应用；不加入最近文档、不与原件绑定、不写回原件，并由应用定期清理 |
| 其他附件 | 不属于个人首版可打开类型；后续若允许在 Finder 中显示或交给外部应用，须另行定义类型与确认规则 |
| 远程图片 | 成长版起：用户明确开启后可受控加载；可下载为本地资源 |
| 不支持的本地预览 | SVG、动画图片、类型与内容不一致的文件；显示占位或 Finder 定位 |
| 新插入图片位置 | 文档必须先保存；随后复制到文档同级 `assets` 目录并插入相对引用，不提供保留外部原位置的分支 |
| 附件命名 | 保留可用原名；重名时自动使用递增后缀，不静默替换既有文件；剪贴板图片使用 `image-001` 起的递增名称 |
| 图片撤销 | 撤销只移除 Markdown 引用，不自动删除已经复制到磁盘的文件 |
| 未命名文档资源 | 第一次插入或粘贴图片前先完成 Markdown 首次保存；取消保存时不创建资源 |

### 4.5.1 工作区规模与响应

| 规格项 | 产品规格 |
| --- | --- |
| 生效版本 | 成长版 |
| 基准工作区 | 10,000 份 Markdown、50,000 个总文件、20 GiB 总容量、最深 20 级目录 |
| 同时打开文档 | 至少 50 个标签页；超出时允许继续打开，但可降低非当前文档的即时反馈频率 |

| 搜索响应 | 基准工作区中，95% 的文件名和全文搜索在 2 秒内给出首屏结果，并明确标记仍在补充或已完成 |
| 变化可见 | 单个已知文件新增、移动、重命名或删除后 2 秒内反映到文件树与搜索状态 |

### 4.5.2 结构洞察

| 规格项 | 产品规格 |
| --- | --- |
| 生效版本 | 成熟版 |
| 关系分类 | 入链、出链、断链、孤立文档、明确链接关系、推断关系、来源未知 |

| 推断处置 | 查看证据、在当前源文档的用户选择位置添加指向目标文件或标题的标准 Markdown 相对链接、标记为无关、暂时隐藏、恢复隐藏项目 |

推断本身不是关系事实。只有用户预览并确认标准 Markdown 链接后，才按该链接形成明确关系；不写入专有关系字段。

### 4.6 迁移来源

| 规格项 | 产品规格 |
| --- | --- |
| 生效版本 | 专业版 |

| 来源版本 | 按实际内容预检，不承诺某个第三方产品版本“完全兼容”；每次迁移都展示逐项结果 |

### 4.7 导出与打印

| PDF 失败 | 个人首版 | 生成器失败、最终文件无法打开或基础检查不通过时不报告成功；公共分发级完整负例矩阵后置 |
| PDF 纸张与方向 | 专业版 | A4、A5、Letter、Legal；纵向或横向 |
| PDF 页边距 | 专业版 | 四边可分别设置 10–40 mm |
| PDF 页眉页脚 | 专业版 | 可选文档标题、文件名、导出日期、当前页码与总页数，用户逐项开启 |
| PDF 分页 | 专业版 | 选项为“关闭 / 一级标题前 / 一级与二级标题前”；标题尽量与下一段同页；表格行、代码块、公式和图表无法完整同页时给出可定位提示 |
| PDF 基准保证 | 个人首版 | 当前正文与可用图片能够完整阅读，固定浅色页面不超出可打印宽度；不承诺深色整页输出 |
| 长图 | 专业版 | 格式可选 PNG 或 JPEG；宽度 720–2,400 px，高度预计超过 32,000 px 或体积超过 100 MiB 时在写出前停止并建议 PDF；默认格式见附录 B |
| 网页变体 | 专业版 | 无样式 HTML、带大纲 HTML；沿用 100 MiB 体积上限与自包含隐私规则 |
| 可移植文档包 | 专业版 | `.zip`；根目录包含 Markdown、实际使用的本地资源和 `交付说明.md`；资源缺失或包预计超过 500 MiB 时先列出问题，不生成残缺包 |
| 专业交付模板 | 专业版 | 内置“技术说明”“研究稿件”“长文阅读”三类模板，分别面向代码与结构清晰、引用与分页稳定、长篇连续阅读；模板只组合当前版本已支持的主题、渲染配置、页面、代码呈现和页眉页脚选项，不插入、删除或改写 Markdown |
| 模板边界 | 专业版 | 应用前展示将改变的交付选项；内置模板不可被覆盖，用户可复制后调整为本地模板；本地模板可重命名和删除，不包含脚本、任意样式、字体文件、网络资源或正文副本 |
| 交付隐私 | 个人首版及后续 | 不包含绝对本地路径或可执行脚本；公开预览前再扩展元数据负例合同 |

## 6. 验收场景

1. 全库搜索精确数值、默认值、快捷键和状态文案时，分别只能在对应附录找到权威定义。
2. 文件编码、换行、视图尺寸、恢复、资源和导出的边界在各功能流程中可被引用，不出现第二套值。
3. 超出每个数值边界时，界面拒绝无效值并保留最近有效值。
4. 对所有支持格式与不支持格式各有正向与降级验收场景。
5. 插件发布、评价、交易与更新状态覆盖完整正向和退出路径；人工智能付费任务同时受三项有限上限约束，不存在无上限或无法封顶仍执行的路径。
