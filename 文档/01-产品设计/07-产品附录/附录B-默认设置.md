## 1. 目标

确保用户首次打开 Inflow 即可开始写作，不必先完成配置；同时确保用户明确选择过的工作区体验在跨文档、跨窗口和应用重启后始终一致。

## 2. 范围

- 全局初始值与新窗口起点。
- 编辑、预览、导航、呈现、资源与历史开关。
- 最近视图和窗口恢复的特例。
- 设置作用域与恢复默认语义。

## 3. 用户故事与使用流程

1. 新用户打开第一个窗口，直接使用下表中已经进入当前版本的初始值；后续版本设置不提前展示。
2. 用户主动修改视图或工作区偏好后，产品立即保存选择；打开其他文档、窗口或重新启动应用时继续使用该选择。
3. 用户选择恢复默认后，选定设置回到下表的值，用户文档和历史内容不受影响。

## 4. 功能规则与默认值

### 4.1 个人首版窗口起点

| 上下文 | 视图起点 | 后续规则 |
| --- | --- | --- |
| 普通启动（无待打开目标） | 源码编辑 | 双击或普通启动 Inflow 时创建一份空白未命名文档并聚焦编辑器，不显示启动页或文件选择器 |
| 新建未命名文档 | 源码编辑 | “文件 > 新建”或 `⌘N` 在独立单文件窗口创建文档并聚焦编辑器；从项目窗口执行也不在项目内创建文件 |
| 打开已有文档 | 实时预览（分栏） | 仅在写作视图仍为“自动（按文档情境）”时使用；文档大纲的产品初始值为折叠 |
| 打开项目 | 暂无当前文档 | 项目目录树的产品初始值为在左侧显示；没有当前文档时右侧大纲不显示，选择 Markdown 后使用当前工作区偏好 |
| 恢复快照 | 源码编辑 | 作为未命名文档打开，用户检查后自行保存 |

个人首版提供源码编辑、实时预览（分栏）和阅读预览三种稳定视图。用户明确选择任一种后，后续文档和应用重启都沿用该选择；选择“自动（按文档情境）”后才恢复上表的上下文起点。

### 4.2 个人首版设置边界

个人首版的设置页包含独立“工作区”分组，统一管理六项应用级偏好：写作视图、项目目录树显隐、文档大纲显隐、目录树宽度、大纲宽度和实时预览源码占比。工具栏、菜单、栏头按钮和分隔条与设置页读写同一值；任何入口修改后立即影响当前与之后的窗口，并永久保存到用户再次修改或恢复默认。

已稳定实现的其他编辑与预览设置可以继续保留，但不得成为打开、编辑、手动保存、恢复、预览或 PDF 的前置。自动保存和完整设置矩阵仍在准备后续体验范围时重新评审。

### 4.3 个人首版固定行为

| 项目 | 固定值 | 说明 |
| --- | --- | --- |
| 保存 | 仅手动保存 | 使用 `⌘S`；不提供自动保存 |
| 打开 Markdown | 复用最多一份未改动的空白未命名文档窗口，否则打开新窗口 | Finder、“打开方式”、系统默认应用、菜单与 Dock/Finder 中 Inflow 应用图标的拖放使用同一路由；已有输入的未命名文档保持不变，同一路径已经打开时只聚焦现有窗口 |
| 一次打开多个 Markdown | 每个文件分别打开或聚焦 | 先规范化并去重；重复目标不消耗空白窗口，最多一个可复用空白窗口承接第一个尚未打开的目标，不为外部冷启动额外保留空白窗口 |
| 打开文件夹项目 | 去重后复用最多一份未改动的空白未命名文档窗口，否则打开项目窗口 | 同一项目根目录已经打开时只聚焦现有项目窗口；已有输入的未命名文档保持不变，外部冷启动不额外创建空白文档 |
| macOS 默认应用 | 跟随用户的系统选择 | Inflow 可被用户设为 `.md`、`.markdown` 的默认应用，但不主动替用户更改该选择 |
| 项目内 Markdown | 原生标签组中的独立文档 | 项目刚打开或空项目可以没有当前文档；从项目侧栏或项目内链接选择时，已打开目标直接聚焦对应标签，新目标加入同一标签组；不因切换要求保存或放弃其他标签的修改 |
| 项目内新建 Markdown | 目录树按钮或右键菜单 | 选中目录时使用该目录，选中文件时使用其父目录，无选择时使用项目根目录；确认后立即创建空文件、更新目录树并打开，`⌘N` 不走此流程；创建成功但打开失败时保留文件与树节点 |
| 项目目录树 | 首次使用时在左侧显示 | “显示目录树”为菜单勾选项，工具栏也有同义入口；修改后作为应用级偏好跨文件、窗口和重启保留 |
| 文档大纲 | 首次使用时折叠 | 大纲栏头可折叠、工作区右边缘可展开；菜单与工具栏入口更新同一应用级偏好；没有当前文档时入口不可用 |
| 主窗口尺寸 | 新窗口 1,200 × 760 pt；最小 820 × 520 pt | 为目录树、编辑/预览与大纲同时显示预留可用宽度；恢复窗口时仍优先采用该窗口自己的尺寸 |
| 系统“打开最近” | 仅在 macOS 实际提供可用记录时附带显示 | 不保证存在、容量或授权恢复，不作为个人首版能力或通过门槛；Inflow 管理的最近文档后置 |
| 编辑器 | 15 pt、1.6 倍行高、自动换行 | 个人首版不要求设置入口 |
| 目录树宽度 | 首次使用 228 pt | 可在附录 A 的范围内拖动；修改后持久保存 |
| 大纲宽度 | 首次使用 228 pt | 可在附录 A 的范围内拖动；修改后持久保存 |
| 分栏 | 首次使用 50% / 50% | 用户可在附录 A 的范围内拖动；修改后持久保存 |
| 三种视图 | 源码编辑 / 实时预览（分栏） / 阅读预览 | `⌘1` / `⌘2` / `⌘3` 切换，共享同一 Markdown 缓冲、修改状态、保存路径和撤销历史；明确选择后持久保存 |
| 即时渲染编辑 | 非当前块弱化/隐藏标记，当前块显示必要标记 | 复杂或错误结构聚焦时回退对应局部 Markdown 源码 |
| 粘贴 | 文本类载荷为纯文本 | 文本、RTF 与 HTML 不保留来源样式或隐藏格式；PNG/JPEG 位图载荷按图片插入流程处理 |
| 预览呈现 | 标准主题、正文最大宽度 760 px、外观跟随系统 | PDF 始终使用固定浅色打印主题 |
| 渲染 | CommonMark/GFM 基础及 `flowchart`、`stateDiagram-v2` | 公式、脚注和其他 Mermaid 后置 |
| 图片插入 | 文档先保存，再复制到同级 `assets` 文件夹 | 重名自动使用递增后缀 |
| 拖放 | Markdown 打开文件，文件夹打开项目，编辑区 PNG/JPEG 插入图片 | 项目目录树不接收外部拖入来复制、移动或整理文件 |
| 辅助使用 | 跟随系统增强对比度与减少动态效果 | 保留基本键盘操作和非纯颜色状态表达 |
| PDF | A4、纵向、四边 20 mm、浅色 | 个人首版固定 |

### 4.5 作用域与优先级

| 作用域 | 用途 | 优先级 |
| --- | --- | --- |
| 文档属性 | 编码、BOM、主换行等必须随文档保留的语义 | 最高 |
| 项目/工作区覆盖 | 当前项目或后续工作区的编辑、预览、资源和导出偏好 | 高于全局默认；个人首版界面只称“项目” |
| 应用级工作区偏好 | 当前与之后文档、窗口和未覆盖项目的视图与布局 | 基础；用户修改后持久保存 |
| 瞬时窗口状态 | 滚动、选区和焦点等当前会话状态 | 独立，不改变内容语义 |

个人首版中，写作视图、目录树与大纲显隐、三处分栏尺寸不得再复制为窗口级偏好；所有入口必须更新同一应用级工作区偏好。滚动、选区和焦点仍按当前会话管理。

### 4.6 不可关闭的保护

以下项目不是个性化开关：

- 保存失败时保留当前编辑和修改标记。
- 每个文档一个最新轻量恢复快照。
- 外部修改与删除提示，以及覆盖前的明确确认。
- 危险链接、脚本、导航和未授权资源的安全边界。

## 5. 异常与空状态

- 无保存偏好时使用本附录默认，不阻断文档打开。
- 值超出附录 A 规格时，保留最近有效值并说明可用范围。
- 旧版本值已不受支持时，选择最近安全值，向用户告知变化，不改写文档。
- 恢复默认只重置选中偏好，不删除文档、最近文件、恢复内容或本地版本时间线。

## 6. 验收场景

1. 普通启动、新建、打开已有文件、打开项目和恢复快照分别使用第 4.1 节的视图起点；无外部目标时双击或普通启动 Inflow 不显示启动页或文件选择器，直接进入可编辑未命名文档。
2. 自动保存不会出现或写回用户文件，`⌘S` 和关闭确认可完成保存闭环。
3. 固定设置在产品负责人的真实项目上可完成源码编辑、实时预览（分栏）、即时渲染编辑和基础 PDF；三种视图不产生第二份正文。
4. 产品默认下，新项目窗口在左侧显示项目目录树；选择 Markdown 后，右侧大纲保持折叠。两侧可从各自栏头或对应工作区边缘独立折叠和展开，不改变 Markdown 或撤销历史。
5. 从网页或富文本应用粘贴时只写入纯文本；复杂或错误块在即时渲染编辑中原位回退局部源码。
6. 设置或工作区入口中改变视图、两侧显隐和三处分栏尺寸后，切换项目文件、打开其他文档并退出重开应用，所有值仍保持；恢复“工作区”默认后回到本节初始值。
7. 自动保存和其他后续完整设置不作为个人首版的隐藏依赖或验收门槛。
8. Finder、系统“打开方式”、默认应用、菜单和 Dock/Finder 中 Inflow 应用图标的拖放打开 Markdown 时复用未改动空白窗口，保留已有输入，并对多目标和重复路径执行一致的分别打开或聚焦规则。
9. 项目内新建使用目录树选择推导目标目录，完整成功后立即更新并打开；创建成功但打开失败时保留文件与树节点；项目窗口中的 `⌘N` 仍创建独立未命名文档。

## 7. 非范围

- 内部存储字段、数据结构、兼容代码或设置传输方式。
- 无用户价值依据的隐藏调试选项。
- 依赖账号或云端才能生效的基础默认。
