## 1. 目标

确保用户首次打开 Inflow 即可开始写作，不必先完成配置；同时确保恢复默认、新建窗口和跨文档体验始终使用同一组产品决策。

## 2. 范围

- 全局初始值与新窗口起点。
- 编辑、预览、导航、呈现、资源与历史开关。
- 最近视图和窗口恢复的特例。
- 设置作用域与恢复默认语义。

## 3. 用户故事与使用流程

1. 新用户打开第一个窗口，直接使用下表中已经进入当前版本的初始值；后续版本设置不提前展示。
2. 用户主动修改视图或偏好后，产品保留选择；恢复已有窗口时，优先恢复该窗口自己的状态。
3. 用户选择恢复默认后，选定设置回到下表的值，用户文档和历史内容不受影响。

## 4. 功能规则与默认值

### 4.1 个人首版窗口起点

| 上下文 | 视图起点 | 后续规则 |
| --- | --- | --- |
| 新建未命名文档 | 源码编辑 | 启动或 `⌘N` 创建时聚焦编辑器 |
| 打开已有文档 | 实时预览（分栏） | 不记忆全局“最近主动视图” |
| 恢复快照 | 源码编辑 | 作为未命名文档打开，用户检查后自行保存 |

纯预览只是临时隐藏编辑栏的显示状态，不作为个人首版的独立持久化模式。更完整的窗口恢复和最近视图规则后置。

### 4.2 个人首版设置边界

个人首版不以设置界面作为通过条件。编辑与预览使用下节固定默认；稳定实现中已经存在的设置可以继续保留，但不得成为打开、编辑、手动保存、恢复、预览或 PDF 的前置。设置矩阵在准备公共预览时重新评审。

### 4.3 个人首版固定行为

| 项目 | 固定值 | 说明 |
| --- | --- | --- |
| 保存 | 仅手动保存 | 使用 `⌘S`；不提供自动保存 |
| Markdown 文件打开方式 | 始终新窗口 | 同一路径已经打开时聚焦现有窗口 |
| 最近文档 | 跟随 macOS 可用行为 | 不作为个人首版通过门槛 |
| 编辑器 | 15 pt、1.6 倍行高、自动换行 | 个人首版不要求设置入口 |
| 分栏 | 新窗口 50% / 50% | 用户可在当前窗口拖动，不要求跨窗口记忆 |
| 预览 | 标准主题、正文最大宽度 760 px、外观跟随系统 | PDF 始终使用固定浅色打印主题 |
| 渲染 | CommonMark/GFM 基础及 `flowchart`、`stateDiagram-v2` | 公式、脚注和其他 Mermaid 后置 |
| 图片插入 | 文档先保存，再复制到同级 `assets` 文件夹 | 重名自动使用递增后缀 |
| 辅助使用 | 跟随系统增强对比度与减少动态效果 | 保留基本键盘操作和非纯颜色状态表达 |
| PDF | A4、纵向、四边 20 mm、浅色 | 个人首版固定 |

### 4.5 作用域与优先级

| 作用域 | 用途 | 优先级 |
| --- | --- | --- |
| 文档属性 | 编码、BOM、主换行等必须随文档保留的语义 | 最高 |
| 工作区覆盖 | 当前文件夹的编辑、预览、资源和导出偏好 | 高于全局默认 |
| 全局默认 | 新文档、新窗口和未覆盖工作区的起点 | 基础 |
| 窗口状态 | 当前视图、滚动、侧栏和分栏等界面状态 | 独立，不改变内容语义 |

### 4.6 不可关闭的保护

以下项目不是个性化开关：

- 保存失败时保留当前编辑和修改标记。
- 每个文档一个最新轻量恢复快照。
- 外部修改与删除提示，以及覆盖前的明确确认。
- 危险链接、脚本、导航和未授权资源的安全边界。

## 5. 异常与空状态

- 无保存偏好时使用本附录默认，不阻断文档打开。
- 值超出附录 A 规格时，保留最近有效值并说明可用范围。
- 旧版本值已不受支持时，选择最近安全值，向用户告知变化，不改写文档。
- 恢复默认只重置选中偏好，不删除文档、最近文件、恢复内容或本地版本时间线。

## 6. 验收场景

1. 新建、打开已有文件和恢复快照分别使用第 4.1 节的固定起点。
2. 自动保存不会出现或写回用户文件，`⌘S` 和关闭确认可完成保存闭环。
3. 固定设置在产品负责人的真实文档上可完成源码编辑、分栏预览和基础 PDF。
4. 调整当前窗口分栏后不改变 Markdown，重新打开时无需承诺恢复该比例。
5. 后续版本设置不作为个人首版的隐藏依赖或验收门槛。

## 7. 非范围

- 内部存储字段、数据结构、兼容代码或设置传输方式。
- 无用户价值依据的隐藏调试选项。
- 依赖账号或云端才能生效的基础默认。
