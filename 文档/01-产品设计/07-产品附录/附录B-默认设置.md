## 1. 目标

确保用户首次打开 Inflow 即可开始写作，不必先完成配置；同时确保恢复默认、新建窗口和跨文档体验始终使用同一组产品决策。

## 2. 范围

- 全局初始值与新窗口起点。
- 编辑、预览、导航、呈现、资源与历史开关。
- 最近视图和窗口恢复的特例。
- 设置作用域与恢复默认语义。

## 3. 用户故事与使用流程

1. 新用户打开第一个窗口，直接使用下表中已经进入当前版本的初始值；后续版本设置不提前展示。
2. 用户主动修改视图或偏好后，产品保留选择；恢复已有窗口时，优先恢复该窗口自己的状态。
3. 用户选择恢复默认后，选定设置回到下表的值，用户文档和历史内容不受影响。

## 4. 功能规则与默认值

### 4.1 三类窗口上下文矩阵

| 上下文 | 视图起点 | 后续规则 |
| --- | --- | --- |
| 新建未命名文档 | 源码编辑 | 启动、Dock 重开且没有可恢复窗口、或 `⌘N` 创建时聚焦编辑器；不读取最近主动视图 |
| 打开已有文档 | 最近主动使用的视图 | 尚无记录时使用实时预览；“最近主动”只在用户明确切换视图后更新 |
| 恢复窗口 | 该窗口自身保存的视图 | 不被全局最近值覆盖；旧视图已不再可用时进入源码编辑并说明变化 |

这三项是上下文默认，不在附录 A、范围或 UAT 中重复具体值。新建未命名文档不会因为用户刚查看过纯预览而失去可编辑起点。

| 编辑器 | 字号 | 15 pt | 可用范围见附录 A |
| 预览 | 正文最大宽度 | 760 px | 可用范围见附录 A |

### 4.3 首发固定行为

| 项目 | 固定值 | 说明 |
| --- | --- | --- |
| 自动保存延迟 | 1 秒 | 首发不提供延迟设置；成长版起可选附录 A 范围 |
| Markdown 文件打开方式 | 始终新窗口 | 首发不提供复用空白窗口或标签页设置 |
| 最近文档物理容量 | 20 项 | 降低容量设置从成长版起开放；物理修剪规则见附录 A |
| 编辑器行高 | 1.6 倍 | 首发不提供行高设置 |
| 自动换行 | 开启 | 首发不提供关闭设置 |

| 渲染配置 | Inflow 标准 | 首发只提供一种配置 |
| 数学公式与 Mermaid | 按 Inflow Markdown 1.0 呈现 | 首发不提供关闭设置；错误局部降级 |
| 图片插入 | 复制到文档同级 `assets` 文件夹 | 既有外部文件可在每次操作中选择保留原位置；粘贴或新建资源只能进入相对目录 |
| 附件重名 | 每次询问 | 不静默覆盖 |
| 辅助使用 | 跟随系统增强对比度与减少动态效果 | 首发不提供独立覆盖设置 |

### 4.5 作用域与优先级

| 作用域 | 用途 | 优先级 |
| --- | --- | --- |
| 文档属性 | 编码、BOM、主换行等必须随文档保留的语义 | 最高 |
| 工作区覆盖 | 当前文件夹的编辑、预览、资源和导出偏好 | 高于全局默认 |
| 全局默认 | 新文档、新窗口和未覆盖工作区的起点 | 基础 |
| 窗口状态 | 当前视图、滚动、侧栏和分栏等界面状态 | 独立，不改变内容语义 |

### 4.6 不可关闭的保护

以下项目不是个性化开关：

- 保存完整性与保存失败时的内容保留。
- 异常恢复保护。
- 外部修改与删除冲突检测。
- 危险链接、脚本、导航和未授权资源的安全边界。

## 5. 异常与空状态

- 无保存偏好时使用本附录默认，不阻断文档打开。
- 值超出附录 A 规格时，保留最近有效值并说明可用范围。
- 旧版本值已不受支持时，选择最近安全值，向用户告知变化，不改写文档。
- 恢复默认只重置选中偏好，不删除文档、最近文件、恢复内容或本地版本时间线。

## 6. 验收场景

1. 全新安装首次打开时，所有首发版设置与上表一致，后续版本设置不提前展示。
2. 新建未命名文档、打开已有文档和恢复窗口分别符合第 4.1 节，主动切换只更新“打开已有文档”的最近主动视图。
3. 分别关闭语法高亮、滚动同步和标题定位，任一操作不改变另外两项。
4. 工作区覆盖、文档属性和全局默认同时存在时，最终值符合优先级表且来源可见。
5. 恢复默认后所有偏好回到上表值，用户内容和恢复保护未受影响。
6. 插件更新按全局与逐插件偏好执行；撤回检查周期保持可见，设备收到有效撤回清单后立即执行；商业市场上线前自动续费设置不展示，人工智能硬上限只对附录 A 允许的提供方生效。

## 7. 非范围

- 内部存储字段、数据结构、兼容代码或设置传输方式。
- 无用户价值依据的隐藏调试选项。
- 依赖账号或云端才能生效的基础默认。
