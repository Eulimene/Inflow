## 阶段

| 阶段 | 可用能力 | 分发边界 |
| --- | --- | --- |
| E0 | Manager、每扩展独立 launcher/client/Host、LaunchCapability、Local Broker、一次性 PackageVerifier | 仅内部 fixture |
| E1 | 主题、只读诊断、开发者模式、本地自签 Trust Store | 离线、无账号、低权限 |
| E2 | 编辑命令、fenced/block directive、单篇导出、声明式侧栏、Extension Content Tree、官方 WASM 原型 | 本地签名/审核；无网络 |
| E3 | curated 免费市场、MarketBroker、签名 PackReleaseRecord、双签名/透明日志、Revoked 终态 | 官方/邀请制；第三方开放另有门槛 |
| E4 | 官方 typed 连接器、NetworkCredentialBroker、immutable ModelStore、官方 AI Companion/adapter | 高信任人工审核 |
| E5 | 通用 NetworkServicePolicy、第三方 Provider/Tool、付费/企业 | 完整 SSRF/市场治理通过后 |

## 进程与权限

| Target | 首次阶段 | 正文 | 文件 | 网络 | Keychain | 责任 |
| --- | --- | --- | --- | --- | --- | --- |
| Main App | Core | 文档与 Core-approved 数据 | 用户 scope、加密 store | 否 | Recovery/Workspace Index/Sync/AI/State 分域 KEK | UI、文档、Save/Recovery、Workspace Index/store owner、AI response owner |
| ExtensionManager.xpc | E0 | 否 | 插件目录、私有 staging | 否 | Trust Store key | 安装事务、独立 Host client、撤回状态 |
| PackageVerifier.xpc | E0 | 不可信包字节 | source FD、job-private noexec CAS | 否 | 否 | 每 job 一次性解析/扫描；无安装目录写权 |
| LocalCapabilityBroker.xpc | E0 | opaque/批准片段 | 受限 FD | 否 | 否 | peer auth、权限、事务 |
| ExtensionHost.xpc | E0 | 仅低权限 snapshot | 否 | 否 | 否 | 每 authenticated client 独立进程；JS/WASM 计算 |
| MarketBroker.xpc | E3 | 签名目录/包流 | 否 | 固定市场 origin | 否 | catalog、release、revocation、下载流 |
| NetworkCredentialBroker.xpc | E4 | 有预算的一次性 approved 流 | 否 | typed adapter policy | 服务专属 credential | HTTP、凭据应用、双向 stream |
| AI Model Manager | E4 | 否 | model download staging | 固定模型目录 policy | 模型源 credential | 下载与 publish request，不拥有 CAS |
| AIModelStore.xpc | E4 | 否 | versioned immutable CAS | 否 | 否 | 独立 re-hash、发布、FD lease、GC |
| AI Inference Worker | E4 | approved Envelope/response token | leased read-only model FD | 否 | 否 | 每 active request 独立本地推理 |
| Render/Image helpers | Core | 单 job 内容 | leased read-only FD | 否 | 否 | 一次性处理与强资源边界 |
| PDFPostflightHelper.xpc | Core | 单份候选 PDF | job-private unlinked FD | 否 | 否 | 每 job 一次性 parse/strip/allowlist rebuild/二次验证；无用户路径、打印或 spool 权限 |

`NetworkCredentialBroker` 不是 E3 市场联网入口；`MarketBroker` 也不能代理连接器、AI
或扩展请求。E3 网络只执行 [Market Broker Policy](./市场代理策略.json)；
两者的 origin、凭据和消息面完全分离。所有 listener 的 peer、nonce、hash、
expiry 与 replay 规则以 [IPC信任矩阵.json](./IPC信任矩阵.json) 为准。

Release/生态里程碑若缺任何机器证据，或观察到两个 active extension handle 共用 PID/audit
token，CI 必须失败，不能以“XPC 通常按客户端隔离”替代运行时证据。
