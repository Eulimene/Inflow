## 1. 产品概述

Inflow 是一款原生、离线优先的专业 Markdown 编辑器。它以 Typora 的完整写作与文件管理能力作为产品基线，同时通过源码/渲染双工作流、本地数据安全、结构化文档检查和原生 macOS 体验形成优势。

产品不依赖账号、云端服务或网络连接。用户始终直接操作本地文件；Inflow 负责提供可靠的编辑体验、接近最终效果的实时预览、异常恢复以及常用导出能力。

### 1.1 产品目标

1. 用户可以在 3 秒内创建或打开一个 Markdown 文件并开始编辑。
2. 编辑、预览和文件保存均可在完全离线环境下完成。
3. 常用 Markdown 内容在编辑区易于识别，在预览区准确呈现。
4. 自动保存、恢复机制应尽可能避免非正常退出导致的内容丢失。
5. 模式切换、查找替换和格式操作符合 macOS 用户习惯。
6. 在完整产品阶段覆盖 Typora 的核心编辑、组织、图片、主题和导出能力，使 Typora 用户无需牺牲主要工作流即可迁移。
7. 在源码可控性、离线可靠性、文档质量检查和原生性能方面形成可被用户感知的领先体验。

### 1.2 非目标

完整产品仍不包含：

- 账号、云同步、多人协作和评论。
- 将专有云作为文件事实来源；系统文件与用户选择的同步盘仍可正常使用。
- 无安全边界的第三方插件或默认执行文档内脚本；受权限约束的高级扩展接口按独立规范提供。
- iOS/iPadOS 客户端。

文件夹工作区、全文搜索、所见即所得编辑和本地版本历史属于对标路线，但按版本分阶段交付。CLI、批量自动化、发布和图床上传不属于编辑器本体。编辑器为高级开发者提供受限、进程外、显式授权的扩展机制；未来可通过插件市场提供可选的云存储、GitHub 和 AI 扩展，但它们不能接管核心保存逻辑，本地文件始终是事实来源。AI 默认不内置、不强制登录、不绑定单一模型供应商。完整对标范围和差异化策略见 [Typora 对标与差异化路线](./TYPORA_BENCHMARK.md)，产品级扩展边界见 [Inflow 扩展能力规范](../engineering/extensions/OVERVIEW.md)，实现架构见 [扩展系统总体设计](../engineering/extensions/SYSTEM_DESIGN.md)，长期生态方向见 [Inflow 扩展生态战略](./ECOSYSTEM_STRATEGY.md)。

## 2. 目标用户与核心场景

### 2.1 目标用户

- 使用 Markdown 撰写技术文档、笔记、博客草稿的开发者和产品人员。
- 希望本地保存敏感内容、避免云服务的个人用户。
- 需要在编辑源码与检查渲染效果之间频繁切换的写作者。

### 2.2 核心场景

1. 新建文档，边写边预览，保存为本地 `.md` 文件。
2. 从 Finder 打开已有 `.md` 文件，修改后自动或手动保存。
3. 切换为纯预览模式进行阅读或检查排版。
4. 在长文档中查找、替换内容，并通过预览标题快速回到源码位置。
5. 编辑包含代码、表格、任务列表、Mermaid 图和数学公式的技术文档。
6. 将当前文档导出为 HTML 或 PDF，用于分享和归档。
7. 应用异常退出后，重新打开并恢复尚未落盘的内容。
8. 打开本地文件夹，通过文件树、大纲和全文搜索管理一组 Markdown 文档。
9. 在即时渲染编辑、纯源码编辑和源码/预览分栏之间按任务自由切换。
10. 粘贴、拖入、整理图片，并保持文档移动后的相对引用有效。
11. 在导出前检查断链、缺失图片、标题层级和方言兼容性。

## 3. 产品原则

- 本地优先：用户内容默认只存在于用户设备上。
- 内容安全：优先保证输入不丢失，再追求渲染性能。
- 原生一致：窗口、菜单、快捷键、文件面板和撤销行为符合 macOS 习惯。
- 渐进增强：标准 Markdown 即使不依赖扩展能力也应可读；Mermaid 和公式为增强渲染。
- 少打扰：界面服务于写作，不引入账号、推荐或运营入口。
- 兼容迁移：Typora 用户的常用语法、文件组织、主题与导出路径应有明确迁移方案。
- 可验证：任何所见即所得操作都必须产生可预测、可查看、可撤销的 Markdown 源码。

## 4. 信息架构与窗口结构

Inflow 同时支持文档窗口与工作区窗口。文档窗口直接编辑单个文件；工作区窗口以用户选择的文件夹为边界，提供文件树、全文搜索、大纲和多文档标签页。两种窗口共享同一编辑、渲染和保存管线。

窗口由以下区域构成：

- 标题栏/工具栏：文件名、模式切换、主题和导出入口。
- 可折叠侧栏：文件树、文件列表、全文搜索和文档大纲。
- 标签栏：展示当前工作区内打开的多个文档，可在设置中关闭。
- 编辑区：Markdown 源码输入及基础语法高亮。
- 预览区：渲染后的 HTML 内容。
- 查找替换条：按需显示，不长期占用空间。
- 状态信息：可选显示保存状态、字数或当前缩放，不作为 MVP 强依赖。

四种显示模式：

| 模式 | 快捷键 | 内容 | 默认焦点 |
| --- | --- | --- | --- |
| 编辑 | `⌘1` | 仅编辑区 | 编辑器 |
| 实时预览 | `⌘2` | 编辑区与预览区分栏 | 保持切换前焦点；首次进入时为编辑器 |
| 纯预览 | `⌘3` | 仅预览区 | 预览区 |
| 即时渲染编辑 | `⌘4` | 在可编辑内容中隐藏非当前块 Markdown 标记 | 即时渲染编辑器 |

Phase 0 首次启动默认进入实时预览模式；即时渲染编辑在 Phase 1 交付。应用记住用户最近使用的模式，并将其用于之后新开的窗口；恢复窗口时保留该窗口原模式。

## 5. 功能需求

### 5.1 文件操作

#### 5.1.1 新建

- 支持菜单“文件 > 新建”和快捷键 `⌘N`。
- 新文档初始内容为空，暂命名为“未命名”。
- 首次保存时弹出系统保存面板，默认扩展名为 `.md`。
- 若用户输入其他扩展名，应提示或自动补全 `.md`，但允许用户明确选择 `.markdown`。

#### 5.1.2 打开

- 支持菜单“文件 > 打开…”和快捷键 `⌘O`。
- 使用系统文件选择器，默认筛选 `.md` 和 `.markdown`。
- 支持 Finder 双击、拖放到应用图标，以及“打开方式”。
- 文件以 UTF-8 为默认编码读取；无法解码时给出错误提示，不覆盖原文件。
- 同一路径已在 Inflow 中打开时，聚焦已有窗口，不重复打开。

#### 5.1.3 保存与另存为

- `⌘S` 保存当前文件；未命名文档执行首次保存。
- `⇧⌘S` 另存为，成功后当前窗口切换到新文件。
- 写入采用安全保存策略：先写临时内容，再原子替换目标文件。
- 保存失败时明确显示原因并保留编辑内容。
- 检测文件被外部程序修改；当内存内容也有未保存修改时，不静默覆盖，提示用户选择保留当前内容、重新载入或另存为。

#### 5.1.4 关闭

- 已保存或自动保存成功的文档可直接关闭。
- 未命名且有内容的文档、或保存失败后仍有修改的文档，关闭时询问“保存 / 不保存 / 取消”。

### 5.2 编辑器

- 支持纯文本输入、选择、复制、剪切、粘贴和系统拼写检查；拼写检查可由用户在设置中关闭。
- 支持撤销 `⌘Z`、重做 `⇧⌘Z`，撤销栈以文档窗口为单位。
- 保持 Markdown 源码为唯一可编辑数据源，预览不直接编辑。
- 支持 Tab 输入与列表缩进；Shift+Tab 减少列表缩进。
- 支持设置编辑器字号，范围 12–28 pt，默认 15 pt。
- 编辑器使用等宽系统字体，首版不提供字体选择。

#### 5.2.1 基础语法高亮

高亮至少覆盖：

- 一级至六级标题。
- 粗体与斜体标记。
- 行内代码与围栏代码块。
- 链接文本与 URL。
- 引用标记。
- 有序、无序和任务列表标记。
- 表格分隔符。

高亮只改变文字样式，不修改源码。输入时应进行增量或节流刷新；10,000 行普通文本下不应因全量同步高亮造成明显卡顿。

用户可关闭语法高亮。关闭后编辑器按普通纯文本显示，但不影响 Markdown 预览和导出。

### 5.3 Markdown 渲染

预览支持 CommonMark 基础语法及以下常用扩展：

- 标题与段落。
- 粗体、斜体、删除线。
- 链接与自动链接。
- 块引用。
- 有序列表、无序列表和嵌套列表。
- GitHub 风格任务列表；预览中的复选框首版只读。
- 行内代码与围栏代码块。
- 表格。
- 水平分隔线与图片。

渲染失败不能阻塞编辑；有问题的片段显示为源码或错误占位，其余内容继续展示。

### 5.4 实时预览

- 用户输入后 150 ms 左右触发防抖渲染；持续输入时可延迟，但停止输入后 300 ms 内应完成普通文档预览更新。
- 分栏模式下编辑区与预览区均可独立滚动。
- 拖动分隔条调整分栏比例，范围 25%–75%，默认编辑区占 50%。
- 记住用户设置的分栏比例。
- 切换模式不改变光标位置、文本选择或滚动位置。

### 5.5 预览主题与正文宽度

- 提供浅色、深色两套内置预览主题。
- 主题可选择“跟随系统 / 浅色 / 深色”，默认跟随系统。
- 主题切换只影响预览区，不改变文档内容。
- 预览正文最大宽度可设置为 600–1,200 px，默认 760 px；窗口较窄时自动适配。
- 代码、表格和 Mermaid 图可在正文容器内横向滚动，不能强制撑破窗口。
- 用户可选择是否加载远程图片，默认关闭；打开后仅在预览与导出时按需联网加载，不缓存至文档目录。

### 5.6 格式辅助

首版通过“格式”菜单提供以下操作；如有文本选择则包裹选择，无选择则插入模板并定位光标：

- 标题（一级至六级）。
- 粗体、斜体。
- 链接。
- 引用。
- 有序列表、无序列表、任务列表。
- 行内代码、代码块。
- 表格模板。

格式操作必须保持源码可读，不引入私有标记。

### 5.7 查找与替换

- `⌘F` 打开查找条，支持上一个、下一个和结果数量。
- `⌥⌘F` 打开查找与替换。
- 支持替换当前项、全部替换。
- 默认区分纯文本字面值，不启用正则表达式。
- 支持区分大小写开关。
- 查找范围为当前文档源码；纯预览模式调用查找时自动切至编辑或分栏模式并聚焦结果。

### 5.8 自动保存与异常恢复

自动保存区分两类文档：

- 已有文件：编辑停止达到用户设置的自动保存延迟后保存到原文件，默认 1 秒；应用进入后台或窗口关闭前立即尝试保存。
- 未命名文档：不创建用户可见文件，而是将恢复快照保存至应用容器。

恢复要求：

- 编辑过程中周期性保存恢复快照，最长间隔 5 秒。
- 快照至少包含源码、原文件路径、光标位置、选择范围、显示模式、滚动位置和最后更新时间。
- 正常保存成功后清理对应的过期快照。
- 非正常退出后，下次启动显示恢复窗口，列出可恢复文档的名称、路径与时间。
- 用户可以逐个恢复、放弃，或全部恢复；放弃前需二次确认。
- 若原文件在异常期间被外部修改，恢复内容打开为独立未命名文档，不直接覆盖磁盘文件。

### 5.9 源码定位与滚动同步

#### 5.9.1 点击标题定位源码

- 预览中的 H1–H6 标题可点击。
- 点击后，在分栏模式聚焦编辑器并将对应标题源码滚动到可视区域中央，同时将插入点放到标题行。
- 在纯预览模式点击标题时切换到分栏模式后完成定位。
- 重名标题按渲染时携带的源码位置精确定位，而不是按标题文本搜索。
- 用户可关闭点击标题定位；关闭后预览标题不响应定位操作，也不会触发模式切换。

#### 5.9.2 基础滚动同步

- 编辑器滚动时，预览根据邻近块级节点的源码行号进行锚点插值滚动。
- 预览滚动时不强制反向驱动编辑器，避免双向争抢；可在后续版本评估双向同步。
- 用户正在手动滚动预览时，暂停编辑器到预览的同步约 1 秒。
- 切换模式后尽量保持当前语义位置，而不是只保持绝对滚动百分比。
- 用户可关闭滚动同步；关闭后两个区域始终独立滚动，点击标题定位仍可单独使用。

### 5.10 Mermaid

- 支持围栏代码块语言标识 `mermaid`。
- 预览时将合法 Mermaid 源码渲染为 SVG。
- 所有渲染资源随应用内置，离线可用，不访问 CDN。
- Mermaid 代码只在本地受控预览环境执行；关闭外部网络加载和任意导航。
- 语法错误时显示清晰的内联错误卡片，同时保留原源码可编辑。
- 主题跟随预览主题重新渲染。
- 用户可关闭 Mermaid 渲染；关闭后 `mermaid` 围栏块按普通代码块展示。

首版目标语法覆盖由内置 Mermaid 版本决定，至少验收流程图、时序图、类图和状态图。

### 5.11 数学公式

- 支持 `$...$` 行内公式与 `$$...$$` 块级公式。
- 使用随应用内置的数学排版资源，完全离线渲染。
- 公式错误时显示原始表达式和非阻断错误提示。
- 公式中的普通美元符号应尽量避免误解析；转义 `\$` 显示为美元符号。
- 用户可关闭数学公式渲染；关闭后公式定界符和内容按普通文本展示。

### 5.12 导出

首版支持导出：

1. HTML：生成单个自包含 `.html` 文件，内联当前预览主题 CSS；Mermaid 图与公式导出为已渲染的 SVG/HTML，不依赖网络资源。
2. PDF：使用当前预览主题和正文宽度生成 PDF；深色预览主题导出时保持深色页面背景和对应前景色，不自动转换为浅色打印样式。分页时尽量避免标题与其后首段分离，代码块和表格必要时跨页或缩放。

导出通过“文件 > 导出”进入，使用系统保存面板。导出不改变当前 Markdown 文件路径或保存状态。导出失败时显示可理解的错误，不产生残缺目标文件。

### 5.13 功能开关原则

以下体验增强功能由用户决定是否启用：自动保存、语法高亮、拼写检查、滚动同步、点击预览标题定位、Mermaid 渲染、数学公式渲染和远程图片加载。

- 所有开关均提供安全、可预期的默认值，修改后立即生效并保存到本机。
- 关闭增强功能不得修改 Markdown 源码，也不得移除对应内容。
- Mermaid 或数学公式关闭时，导出结果与当前预览行为一致，按普通代码或文本处理。
- 涉及网络访问的远程图片加载默认关闭，并在设置项旁明确标注隐私影响。
- 异常恢复、原子保存、外部修改冲突检测和渲染安全限制属于数据安全能力，不允许关闭。

### 5.14 本地链接与跳转

Inflow 支持标准 Markdown 本地导航，不要求用户写入 Inflow 私有链接协议。

支持的目标：

- 当前文档标题：`[安装](#安装)`。
- 相对路径文档：`[配置](./configuration.md)`。
- 跨文档标题：`[主题设置](./configuration.md#主题设置)`。
- 父级或子目录文档：`[设计](../design/overview.md)`。
- 本地图片、PDF 和其他附件链接。

交互规则：

- 纯预览和分栏预览中，单击链接执行导航。
- 源码编辑与即时渲染编辑中，`⌘`+单击执行导航，普通单击仍用于定位光标。
- 当前文档锚点在当前视图内滚动，并保持返回位置。
- 指向 Markdown 文件的链接由 Inflow 打开；工作区模式默认在当前窗口新标签页打开，单文档模式在新窗口打开。
- 跨文档锚点在目标文件打开后定位到对应标题。重名标题使用与当前渲染配置一致的稳定 slug 规则。
- 非 Markdown 文件交由系统默认应用打开；执行前必须确认目标位于用户已授权范围内。
- HTTP/HTTPS 链接使用系统浏览器打开，并明确离开 Inflow。
- `javascript:`、可执行文件和未经授权范围的 `file:` 链接禁止直接打开。
- 目标缺失、标题不存在或权限不足时显示非阻断错误，并提供“在 Finder 中查找”或“重新授权目录”。

导航维护每个文档窗口的前进/后退历史，记录文档 ID、标题锚点和语义滚动位置。提供“后退”和“前进”菜单操作；具体默认快捷键在交互设计阶段确定，避免与编辑快捷键冲突。

文档健康中心将检查本地断链、缺失锚点和大小写不一致路径。路径修复必须显示差异并可撤销。

## 6. 设置

设置保存在本机用户偏好中，对所有文档生效。设置窗口按“通用、编辑器、预览、扩展”分组，支持恢复默认设置。

| 分组 | 设置项 | 默认值 | 范围/选项 |
| --- | --- | --- | --- |
| 通用 | 自动保存 | 开启 | 开启 / 关闭 |
| 通用 | 自动保存延迟 | 1 秒 | 0.5 / 1 / 2 / 5 秒；仅自动保存开启时可用 |
| 通用 | Markdown 文件打开方式 | 工作区标签页 | 工作区标签页 / 新窗口；单文档模式固定为新窗口 |
| 编辑器 | 编辑器字号 | 15 pt | 12–28 pt |
| 编辑器 | Markdown 语法高亮 | 开启 | 开启 / 关闭 |
| 编辑器 | 系统拼写检查 | 开启 | 开启 / 关闭 |
| 编辑器 | 自动换行 | 开启 | 开启 / 关闭 |
| 预览 | 预览正文宽度 | 760 px | 600–1,200 px |
| 预览 | 分栏比例 | 50% | 25%–75% |
| 预览 | 预览主题 | 跟随系统 | 跟随系统 / 浅色 / 深色 |
| 预览 | 编辑器到预览滚动同步 | 开启 | 开启 / 关闭 |
| 预览 | 点击标题定位源码 | 开启 | 开启 / 关闭 |
| 预览 | 加载远程图片 | 关闭 | 开启 / 关闭；开启时显示联网与隐私说明 |
| 扩展 | Mermaid 渲染 | 开启 | 开启 / 关闭 |

关闭自动保存时仍保留异常恢复快照；手动保存、关闭提醒和恢复机制继续生效。恢复默认设置只重置偏好，不改动文档内容、最近文件或恢复快照。

## 8. 状态与异常处理

- 保存中：标题栏显示短暂进度状态，但不阻塞编辑。
- 已保存：不持续展示强提示，可在标题栏移除修改标记。
- 保存失败：显示非模态错误提示，并提供“重试”和“另存为”。
- 文件不存在：若已打开文件被外部删除，保留内存内容并提示另存为。
- 文件无权限：以只读方式打开，允许复制或另存为。
- 预览失败：编辑器继续可用，可重试预览。
- Mermaid/公式单块失败：只影响对应内容块。
- 大文件：预览和高亮允许降级或延迟，但文本编辑和保存必须保持可用。

## 9. 非功能需求

### 9.1 平台与隐私

- 最低支持 macOS 14 Sonoma。
- 仅支持 Apple Silicon，不提供 Intel/x86_64 构建，也不通过 Rosetta 作为正式支持路径。
- 核心界面使用 SwiftUI，编辑器可按能力需要桥接 AppKit 文本系统。
- 暂不通过 Mac App Store 分发；采用 Developer ID 签名和 Apple 公证的独立安装包直接分发。
- 正式发布必须通过 Gatekeeper 校验；应用更新机制在技术方案中单独确定，不以 Mac App Store 为依赖。
- 默认不采集文档内容、文件路径或使用数据。
- 不发起网络请求；帮助链接等显式外部操作除外，且须由用户主动触发。
- 应用沙盒化，文件访问使用系统授权和安全作用域书签。

### 9.2 性能指标

在基准设备（Apple M1、8 GB 内存）上：

- 冷启动至可输入：不超过 2 秒。
- 打开 1 MB / 10,000 行普通 Markdown：不超过 2 秒。
- 普通输入到预览更新：P95 不超过 300 ms。
- 模式切换：P95 不超过 150 ms。
- 连续输入过程中主线程不得出现超过 100 ms 的可感知冻结。
- 典型 1 MB 文档内存占用目标不超过 300 MB；复杂 Mermaid 内容单独评估。

### 9.3 可靠性

- 保存使用原子写入，任何失败不得破坏最后一次成功保存的文件。
- 恢复快照必须采用版本化数据结构，以支持应用升级。
- 导出和渲染任务可取消，不能阻塞关闭文档或保存源码。

### 9.4 可访问性与本地化

- 所有按钮提供 VoiceOver 标签和键盘可达能力。
- 支持系统增大对比度和减少动态效果设置。
- 浅色、深色主题下文本和关键控件对比度满足 WCAG 2.1 AA 的常用阈值。
- 首版界面支持简体中文；代码和数据结构为英文命名，为后续英文界面预留本地化资源。

## 10. 数据与技术边界

### 10.1 文档数据

Markdown 源码是文档事实来源。渲染 HTML、语法高亮结果、标题锚点和源码映射均为可重建派生数据，不写入 `.md` 文件。

### 10.2 本地持久化

- 用户文档：用户选择的位置。
- 恢复快照：应用容器的 Application Support 目录。
- 用户设置：UserDefaults 或等价偏好存储。
- 安全作用域书签：应用容器内受保护持久化。
- 临时渲染与导出文件：系统临时目录，任务完成后清理。

### 10.3 渲染安全

- 默认不执行 Markdown 中的任意脚本。
- 原始 HTML 的首版策略为转义或清洗后渲染，不允许 `<script>`、事件处理属性及远程资源绕过限制。
- 预览 WebView 禁止任意导航、窗口打开和未经用户发起的下载。
- 本地图片仅在当前文档授权范围内加载；远程图片首版默认不加载，以满足离线和隐私原则。

## 11. MVP 优先级

### P0：首个可发布版本

- 新建、打开、编辑、保存、另存为和多窗口文档模型。
- 三种模式与 `⌘1`、`⌘2`、`⌘3`。
- 需求中列出的 Markdown 基础元素和语法高亮。
- 浅色/深色/跟随系统主题。
- 字号、正文宽度、分栏比例设置。
- 撤销、重做、查找和替换。
- 自动保存与异常恢复。
- 点击标题定位源码和编辑器到预览的基础滚动同步。
- HTML、PDF 导出。
- Mermaid 与数学公式离线渲染。
- 沙盒权限、错误处理、基础辅助功能。

### P1：发布后优化

- 即时渲染编辑模式与 `⌘4`。
- 文件夹工作区、文件树、标签页、大纲、全文搜索和快速打开。
- 双向滚动同步、代码语法着色和至少 6 套内置主题。
- 图形化表格、可点击任务列表、Smart Paste、脚注、TOC、YAML Front Matter 和 Alerts。
- 图片粘贴、相对路径、附件目录和资源移动。
- 专注模式、打字机模式、行号、字数统计和自定义 CSS。
- 打印、长图、增强 PDF 和更多导出格式。

### P2/P3：全面对标与领先能力

- 编辑器内的增强 PDF、HTML、长图与可移植文档包导出。
- 文档健康中心、渲染配置档案、本地版本时间线和冲突差异视图。
- 资源管家、可移植文档包、大纲拖动重组和结构化批量编辑。
- 面向高级开发者的扩展 SDK、开发者模式、权限管理和扩展故障隔离。
- 后续生态阶段提供签名插件市场及云存储/GitHub 连接器；不进入首发和基础对标版本。
- AI 作为后续生态能力，支持本地或远程 Model Provider、AI Action、受控上下文和工具调用；不进入编辑器核心依赖。
- 详细范围、完成标准和指标以 [Typora 对标与差异化路线](./TYPORA_BENCHMARK.md) 为准。

## 12. 验收标准

版本达到以下条件才可视为 MVP 完成：

1. 在断网状态下完成新建、编辑、预览、保存、重开和导出全流程。
2. 所有规定快捷键在编辑器聚焦时仍能正确响应，且不会意外输入文本。
3. 标准验收样例中的标题、段落、粗体、斜体、链接、引用、列表、任务列表、代码块和表格正确渲染。
4. Mermaid 流程图、时序图、类图、状态图及行内/块级公式可离线渲染。
5. 点击任意重复标题仍能定位到其准确源码行。
6. 编辑区滚动跨越长文档时，预览能跟随到相近语义块；用户手动滚动预览时无明显争抢。
7. 强制终止应用后重新启动，可恢复最多 5 秒前的未保存内容。
8. 模拟磁盘写入失败时，原文件保持完整，编辑内容仍留在内存或恢复快照中。
9. 外部修改冲突不会被 Inflow 静默覆盖。
10. HTML 和 PDF 导出包含当前主题、表格、公式及 Mermaid 结果，断网打开仍完整。
11. 1 MB / 10,000 行基准文档满足第 9.2 节性能目标，或有明确且不影响编辑保存的降级提示。
12. VoiceOver 可读出主要工具栏控件、模式状态和错误提示。
13. 各功能开关修改后立即生效，重启应用后保持；关闭功能不会改写源码，恢复默认设置不会删除用户数据。
14. 当前文档、相对 Markdown 文件和跨文档标题链接均能正确跳转；前进/后退恢复语义位置，越权或危险链接不会被直接打开。

## 13. 测试样例集合

开发阶段维护一份统一的 Markdown 验收文档，至少包含：

- 六级标题、同名标题和特殊字符标题。
- 多层列表、混合列表、已完成和未完成任务项。
- 中英文粗体/斜体、嵌套格式、链接和转义字符。
- 多语言代码块、超长代码行和反引号边界。
- 表格、超宽表格、缺失单元格和对齐方式。
- Mermaid 合法/非法示例及四类目标图表。
- 行内/块级公式、美元符号和非法公式。
- 10,000 行长文档、1 MB 文档和大量标题文档。
- 本地图片、远程图片、原始 HTML 和潜在脚本注入内容。

## 14. 关键风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 原生文本系统与增量高亮复杂 | 输入卡顿、撤销异常 | 将文本存储与样式更新解耦，先建立性能基准 |
| Markdown 渲染与源码位置映射不稳定 | 标题定位、滚动同步不准 | 渲染阶段保留 source range，并为块级节点注入稳定 ID |
| Web 预览与离线资源集成复杂 | 导出或主题不一致 | 统一预览与导出的渲染管线，所有依赖打包进应用 |
| 自动保存覆盖外部修改 | 数据损失 | 保存前校验文件版本，冲突时停止自动覆盖 |
| Mermaid 大图计算开销高 | 预览卡顿 | 后台节流、缓存相同源码结果，并允许单块失败 |
| 沙盒下相对图片访问受限 | 预览缺图 | 基于用户授权目录管理安全作用域访问 |

## 15. 后续交付顺序

PRD 确认后按以下顺序推进：

工程架构、技术选型、数据流、测试与实施阶段以 [Inflow 产品技术方案](../engineering/TECHNICAL_DESIGN.md) 为准。

1. 技术方案：工程架构、依赖选型、文档模型、渲染管线、源码映射与恢复机制。
2. 交互与视觉规格：窗口布局、工具栏、设置、错误与恢复流程。
3. 工程初始化：macOS 项目、测试目标、格式规范和持续集成。
4. P0 分阶段实现：文件与编辑器 → 预览 → 保存恢复 → 同步定位 → 导出和扩展渲染。
5. 自动化测试、性能测试、辅助功能检查和发布验收。

## 16. 已确认发布决策

以下决策作为产品与技术方案的正式约束：

1. Inflow 仅支持 Apple Silicon，不提供 Intel 构建。
2. 当前阶段不通过 Mac App Store 分发，使用 Developer ID 签名、公证和独立安装包。
3. PDF 导出忠实使用当前预览主题；选择深色主题时，输出保留深色背景。
