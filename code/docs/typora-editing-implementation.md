# Typora 式即时编辑实施记录

对应 [体验差距审查](typora-live-editing-gap-audit.md)，2026-09-23 开始实施。以下逐批记录已实现、自动验证和待实机验收的边界，不把自动测试等同于人工 UAT。

## 第一批：编辑意图与换行

- 新增统一的 `MarkdownEditingTransaction`：先生成文字变更和 UTF-16 选区，再一次性提交给原生编辑器及 Engine 历史。
- 正文 Enter 新建段落，Shift+Enter 插入段内换行；标题末尾进入正文，引用区分段落与续行，列表软换行保留项目缩进；源码模式继续使用原生换行。
- 新输入的围栏与块公式定界符可以通过 Enter 创建可编辑块；代码与公式内不插入正文段落分隔符。
- 段首 Backspace 可合并前后段落。方向键和行首导航避开折叠标记；代码块第一次全选选择块内内容，再次全选选择文档。
- 保留组合输入保护，不在 marked text 期间执行结构命令。

验证：macOS build-for-testing 通过；47 项 RenderedMarkdownEditorTests 通过；个人版测试分类门禁和 diff 检查通过。新回归覆盖正文拆分、软换行、引用、列表、围栏、中文/Emoji 位置和撤销。尚未宣称真实输入法、长文档性能和所有跨块选择通过。

## 第二批：表格导航、阅读栏和数学默认配置

- 表格新增 Cmd+Enter 在当前行下方插入行，并保持所在列；Tab 追加行和菜单插入行共用焦点目标。新增可见的表格行列/对齐菜单和行列数量提示。
- 单元格暴露行列名称及操作说明；打字机模式可定位表格内的实际输入行。
- 即时编辑随窗口宽度保持居中的阅读栏，并使用配置中的内容宽度；源码模式保留原有布局。
- 修正个人版固定配置关闭数学渲染的问题，默认启用 MathJax。视图切换提供明确的可访问性名称。

验证：macOS build-for-testing 通过；48 项编辑器测试和 17 项偏好测试全部通过。100 次原生 Tab 命令依次落在预期单元格，追加行保持同一表格控件；本机同步命令耗时 P50 约 0.23ms、P95 约 4.9ms（不代表输入到屏幕绘制延迟）。覆盖 Cmd+Enter 定位与单元格组字不提前提交。旧偏好测试已按现有 16pt 排版基准更新，并通过等待 Engine 快照替代固定次数调度等待。

## 第三批：渲染主题与失败反馈

- Mermaid、flow、sequence 根据阅读主题生成深浅配色；缓存键包含主题，避免复用另一主题的结果。主题变化可重新派生资源，HTML 输出沿用同一适配规则。
- 无效图表和块公式保留可编辑源码，并显示就地错误说明；右键提供重新渲染入口。
- 代码块菜单提供复制代码内容、编辑语言、完成编辑；代码/公式可用 Cmd+Enter 或 Esc 结束当前块编辑。

验证：macOS build-for-testing、35 个固定 JS 资源校验、diff 检查通过；48 项编辑器回归与 JS 综合渲染用例共 49 项通过。综合用例实际运行三类图表深浅主题、MathJax、高亮和标签换行，并检查主题缓存隔离、SVG/PDF 输出及源码保留。

## 第四批：表格格式保真与剪贴板

- 新增可见文字到 Markdown 的单元格投影。修改链接文字、粗体和行内代码内容时仅更新对应源码范围，保留周围标记；单元格显示基础行内样式。
- 普通复制同时提供 Markdown 和 HTML，普通粘贴支持静态 HTML 转 Markdown；增加“复制 Markdown”和“粘贴纯文本”入口。HTML 转换不执行脚本，拒绝外部实体声明，并过滤不安全链接。
- 保留图片与表格 TSV 原有入口，并在输入法组字期间跳过结构转换。

验证：macOS build-for-testing 通过，49 项编辑器与 20 项 Engine 客户端测试全部通过；测试分类门禁与 diff 检查通过。HTML 转换覆盖常见标题、行内格式、列表和表格，不宣称任意网页样式无损转换。

## 第五批：逻辑选区、历史与结构边界

- Engine 同步记录编辑前选区；表格将可见单元格位置映射到 Markdown，撤销/重做重新定位到对应单元格与 UTF-16 文字位置。结构历史操作同步恢复表格投影，连续 Tab 仍复用控件。
- 修复旧格式检查任务在外部重新载入后可能提交旧文本的竞态；任务执行前复核内容、选区和组字状态，重新载入取消旧检查。
- 列表续行 Enter 回到新项目，嵌套空项逐级退回，任务软换行按项目缩进，Tab 可以移动项目及其连续的子内容。
- Shift 方向键扩选跨隐藏标记时扩到完整边界，普通剪切提供与复制一致的 Markdown/HTML 内容；表格和图片控件加入主编辑器可访问子节点。
- 不支持的部分/混合格式明确显示格式引擎返回的原因；组字期间提示先确认候选，避免静默失败或误报文档变化。

验证：macOS build-for-testing 通过；49 项编辑器、20 项 Engine 客户端、17 项当前格式测试与 1 项综合格式历史测试共 87 项通过。综合格式历史测试曾暴露上述异步竞态，修复后通过。应用菜单检查需要真实宿主，未混入直接测试。实机复验遇到 macOS 锁屏，已请求用户解锁；未将自动测试视为人工验收。

## 第六批：渲染边界、模块拆分与导出

- 将编辑意图和列表规则、剪贴板转换、行内字符映射从渲染模型文件拆为 `MarkdownEditingTransactions.swift`、`MarkdownClipboard.swift`、`MarkdownInlineProjection.swift`。TextKit 控件消费事务，转换层不持有输入焦点。
- 清空格式化单元格会移除孤立标记；跨格式替换先验证在表格上下文中的可见内容，不能保留成对标记时退回正确文字，其他单元格不受影响。
- 表格公式使用 `MarkdownTableMathPreview` 的只读附件投影，聚焦编辑原 TeX；投影不改正文、不进入历史，不再占用整篇文档的表格隐藏位置。公式可随单元格宽度缩放；无公式表格不走额外解析，稳定投影复用缓存。
- MathJax 与图表统一经 WebKit 生成矢量 PDF 再交给原生图像显示，数学主题进入缓存键；仍保留 SVG 作为 HTML 输出。基础浅色 PDF 默认启用公式。
- 修复无窗口 PDF 导出未完成图片布局就开始打印的问题：先确定打印视口，在生成 PDF 前同步完成图片/表格覆盖层布局。
- 暂存回归按文档 ID 检查，避免其他打开文档的草稿导致假失败。无保存询问、临时目录暂存和原文件不被覆盖的产品规则保持不变。

验证：最终构建、集成和完整门禁结果见本文件末尾。宽公式 PDF 通过实际页面像素及打印边界校验；诊断图已查看，不再以“源字符串存在”作为公式已绘制的证据。诊断文件写入和日志代码已从测试及产品代码移除。

## 后续回归：光标与换行（2026-09-23）

本轮重新检查实际窗口与挂载到 NSWindow 的编辑器，确认此前仅验证选区偏移不足以证明光标正确。

- 回车后的字符属性先继承上一段、再等待异步投影修正。标题样例中即时位置与最终位置相差 46.5 点，引用新行也有横向位移。结构编辑现在在滚动和绘制之前应用当前源码的原生布局投影；省略 HTML 生成，图表等 JS 资源仍异步处理，输入历史仍由文档 Engine 管理。
- 中文字体回退会让同一字号的字体度量变化。即时编辑的光标统一使用主题字体的同字号度量；标题仍保留自身字号，正文与空行不再因中英文回退改变光标高度。
- 可见字体查找被限制在当前源码行，空引用不再借用相邻标题或上一行行内格式的字体。
- 自动折行边界保留 AppKit 的选区 affinity。新增回归在修复前捕获了 24 点（整整一行）的错误位移，修复后通过。
- 列表、任务列表的替换标记不再触发整段源码编辑样式；空列表项保留项目符号与缩进。没有正文时，项目符号使用正常字体基线，避免借用隐藏标记的微小字体基线。

验证：`verify-launch.sh --personal` 通过（148 项 Rust、309 项当前直接 XCTest、静态分析等）。最后的空列表符号基线调整后，重新构建并运行全部 49 项渲染编辑器与 20 项 Engine 客户端测试，69 项全部通过。新回归检查正文、标题、引用、列表、任务项、行内格式、LF/CRLF、Enter/Shift+Enter 的即时及最终几何，并覆盖中文输入后光标高度与自动折行边界。实机检查了连续列表回车、退出列表和引用回车后继续输入；不以粘贴中文代替真实输入法组合态验收。
