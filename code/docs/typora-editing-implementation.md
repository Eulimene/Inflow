# Typora 式即时编辑实施记录

对应 [体验差距审查](typora-live-editing-gap-audit.md)，2026-09-23 开始实施。以下逐批记录已实现、自动验证和待实机验收的边界，不把自动测试等同于人工 UAT。

## 第一批：编辑意图与换行

- 新增统一的 `MarkdownEditingTransaction`：先生成文字变更和 UTF-16 选区，再一次性提交给原生编辑器及 Engine 历史。
- 正文 Enter 新建段落，Shift+Enter 插入段内换行；标题末尾进入正文，引用区分段落与续行，列表软换行保留项目缩进；源码模式继续使用原生换行。
- 新输入的围栏与块公式定界符可以通过 Enter 创建可编辑块；代码与公式内不插入正文段落分隔符。
- 段首 Backspace 可合并前后段落。方向键和行首导航避开折叠标记；代码块第一次全选选择块内内容，再次全选选择文档。
- 保留组合输入保护，不在 marked text 期间执行结构命令。

验证：macOS build-for-testing 通过；47 项 RenderedMarkdownEditorTests 通过；个人版测试分类门禁和 diff 检查通过。新回归覆盖正文拆分、软换行、引用、列表、围栏、中文/Emoji 位置和撤销。尚未宣称真实输入法、长文档性能和所有跨块选择通过。

## 后续批次

- 表格命令、选区与焦点、编辑工具及内容保真。
- 公式可见性、图表主题与错误反馈、代码块操作。
- 阅读宽度、输入排版、统一滚动、复制粘贴和可访问性。
- 逐项执行审查中的 A01–A24，记录可自动化与必须实机验证的结果。
