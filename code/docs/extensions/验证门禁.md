## 1. 证据格式

每个 `PASSED` 记录至少绑定：

- clean Git commit 与 dirty=false；
- macOS/Xcode/Rust/运行时精确版本；
- 目标设备与进程身份；
- fixture/corpus/schema/策略的非全零 SHA-256；
- 测试次数、开始结束时间和原始结果摘要；
- 构建产物、签名/公证或服务端发布记录的精确摘要；
- 负责人和复审条件。

任何字段未知、产物摘要漂移、只用 mock 进程、未执行外部服务或依赖尚未存在时，保持 `OPEN`，不能写“自动化闭环”。

## 2. 阶段退出

- E1 需要 EXT-RUNTIME/PACKAGE/BUDGET/OUTPUT、MARKET-REVOKE、Market Broker 对应的 NETWORK-POLICY 和 DATA-LIFECYCLE 全部通过；官方能力中心也不能绕过安全撤回或联网策略。
- E2 需要 E1、EXT-SYNTAX 和对应领域包通过。
- E3 只开放免费市场；需要 E1、MARKET-SUPPLY、MARKET-REVOKE 与 NETWORK-POLICY 通过，Market Broker 不能借用后续阶段网络证据。
- E4 逐能力开放；HIGH-TRUST-HOST 与 DATA-LIFECYCLE 是共同前置，AI、Connector 和 Network gate 再按所开放能力分别通过，不能相互借证据。
- E5 商业与双向同步分别需要账号/商业或同步 gate，通过一个不代表另一个完成。
