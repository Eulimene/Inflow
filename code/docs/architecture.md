# Inflow 架构决策

## ADR-001：macOS 首发与 Rust 跨平台核心

- 状态：已采用
- 日期：2026-08-20

### 决策

Inflow 以 macOS 14+ 为首发平台，客户端使用 SwiftUI 与必要的 AppKit 适配。文档语义、Markdown 分析、统计、诊断与交付前检查等可复用能力放在 Rust 核心中。Swift 和 Rust 通过版本化 C ABI 交互。

### 责任边界

Rust 核心负责：

- 以同一份 Markdown 源文本为内容事实；
- 编码、换行、标题结构、统计、渲染输入与诊断等平台无关逻辑；
- 输出带 ABI 版本的明确数据结构，不访问任意用户文件。

macOS 客户端负责：

- `NSDocument`/SwiftUI 文档生命周期、安全作用域授权与原子写入；
- 窗口、菜单、快捷键、VoiceOver 与其他平台交互；
- 将核心结果呈现给用户，但不维护第二份可编辑正文。

### 安全约束

- Swift 层不直接持有 Rust 内部对象指针。
- 跨 ABI 的所有内存都由分配方释放，后续新增字符串结果时必须成对提供释放函数。
- 文件读写不跨越 ABI，以便权限、冲突和错误始终由原生文档层管理。
- 未来 iOS、Windows 或 Linux 客户端复用 Rust 核心，不复用 macOS 文件与 UI 实现。
