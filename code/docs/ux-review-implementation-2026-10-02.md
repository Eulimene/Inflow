## 范围说明

原评审现场的长时间加载没有完整故障跟踪，因此本轮修复已识别的会话所有权风险，并提供加载失败恢复路径；不能据此断言已经复现当时所有触发条件。新增回归覆盖正常加载、重建视图、模式切换、超时和重试。

跨文档全文搜索、附件诊断、版本历史与高级导出属于原评审的后续功能方向，本轮未扩展产品范围。现有目录过滤、快速打开、阅读历史均继续保留。

## 验证记录

- `scripts/verify-launch.sh --personal`：通过。Rust 148 项、Swift current-direct 355 项全部通过，生成绑定与 JavaScript 资源检查、Rust fmt / Clippy、macOS build-for-testing、Analyze 和 diff 检查通过。
- `scripts/test-launch-gate-scope.sh`：通过。新增 3 项测试已逐项归入 current-direct，清单总计 483 项（355 direct、37 host、86 deferred、5 fixed-performance）。
- `xcodebuild test-without-building`：补验 7 项 App 宿主测试全部通过，覆盖离线 JavaScript、行内标记、跨主题选区与复制、公式、富文本剪贴板、小型及宽幅 Mermaid。其余 30 项 host、86 项 deferred 和 5 项固定性能测试不计为本轮通过。
- `NSHostingView` / `NSWindow` 集成回归：在 1200 × 760 原生视图中反复切换三种模式并重建 SwiftUI 视图，确认正文会话保持一致、表格可见，继续输入后编码内容保持准确。分栏截图人工检查表格行线、完整文字和任务列表符号，结果正常。
- 首轮 4 个旧断言仍期待任务列表双符号与超出正文列宽的表格，已更新为新合同；误用 direct 环境执行宿主测试产生的系统服务失败，改用允许访问系统服务的 App 宿主环境后全部通过。

自动化和截图不替代真实项目中文输入法、拖放、首次关闭说明理解、异常退出等完整人工 UAT。原现场文档的卡住现象尚未取得完整复现轨迹，不能把已通过的回归扩大解释成所有载入异常已经消除。


## 第二轮补充（2026-10-03）

- 首次关闭未保存文档时，在草稿检查点成功之后显示原生说明，提供“返回编辑”和“保留草稿并关闭”。只在明确选择关闭后记住确认；取消关闭、干净文档、空白新文档不消耗首次说明。重复关闭请求不会叠加弹窗，草稿写入失败继续阻止关闭。该路径同时适用于文档关闭和退出前的统一检查。状态栏详情继续保留保存规则。
- 目录侧栏新增“定位当前文件”：清除过滤、展开必要祖先目录、选中并滚动到文件；切换文档时也展开其所在目录。同名文件按项目相对路径区分，项目外或不可定位的文件禁用入口。
- 最近访问顺序改用独立的、最多 100 个 URL 的会话记录。前进、后退会更新访问顺序；关闭标签不会删除该文件的访问记录。快速打开只对当前项目仍存在的匹配文件排序，不会展示其他项目或已删除的文件。
- 空白页标题提示补全为“输入 # 和空格创建标题”，项目标签关闭按钮补齐草稿说明。
- 加载回归扩展到仓库约 1.6 万字符的中文实现文档，覆盖视图重建后替换正文、进入即时编辑、标题排版和原始字节一致性。测试支持通过 `INFLOW_UX_DOCUMENT` 只读加载指定复现文档，截图通过 `INFLOW_UX_SCREENSHOTS` 输出，不写回原文件。
