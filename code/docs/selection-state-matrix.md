# Markdown 格式命令选区状态矩阵

> 状态：后续编辑能力的工程参考，不是个人首版 UI 或 UAT 合同
>
> 作用域：粗体、斜体、删除线、行内代码、代码块、H1–H6、引用、有序/无序/任务列表、清除格式，以及链接、图片、表格、分隔线、脚注、公式和图表插入。

当前个人首版菜单只暴露粗体、斜体、行内代码、H1–H6、引用、无序/有序/任务列表和链接；插入入口只包含链接、PNG/JPEG 图片和固定表格模板。本文的更广命令家族即使存在底层计划或测试，也不得据此扩大当前产品范围。当前口径见 [current-implementation.md](current-implementation.md)。

该矩阵记录底层格式/插入计划、TextKit 应用器和 XCTest 的一致性边界。对于已安装的当前命令，操作要么产生一个完整、可撤销的替换，要么不改变任何字节；不存在部分应用。

## 格式命令

| 选区状态 | 行内格式 | 行/块格式 | 清除格式 | 统一结果 |
| --- | --- | --- | --- | --- |
| 空选区 | 插入最小可编辑定界符，光标置于其中 | 将光标所在完整行转为目标结构；空行插入最小模板 | 不可用 | 单次可撤销编辑，或明确 no-op |
| 完整普通选区 | 排除外围空白后添加标记 | 扩展至完整物理行/语义块后统一转换 | 仅在选区完整包含可清除节点时执行 | 重新解析候选结果后才提交 |
| 完整同类已格式化选区 | 移除一层目标标记 | 移除一层目标结构 | 移除所有完整可清除标记 | 保留内容和其他嵌套语义 |
| 部分命中已有标记/围栏 | 拒绝 | 拒绝 | 拒绝 | 源文、选区和 undo 栈不变 |
| 混合状态 | 拒绝，不猜测用户是要统一添加还是移除 | 标题、引用和列表只在完整行边界按已声明规则统一 | 只清除完整命中的节点 | 无歧义才修改 |
| 单段内软换行 | 仅当候选结果重新解析为一个有效目标节点时执行 | 按完整行/块执行 | 按完整节点执行 | 可单次撤销 |
| 包含空行的跨段多行 | 拒绝；不逐段猜测包裹 | 仅对已定义的完整行/语义块命令执行 | 仅清除完整命中节点 | 粗体/斜体/删除线不按每段分别改写 |
| 嵌套语法 | 只添加或移除目标层，保留其他层 | 保留子结构与缩进 | 仅移除选中且可验证的标记 | 候选结果语义不等于预期则拒绝 |
| IME marked text | 不应用 | 不应用 | 不应用 | 保留组字文本和输入法会话 |
| 只读文档 | 菜单禁用，应用器再次拒绝 | 同左 | 同左 | 无文本、选区或 undo 变化 |
| 过期源文/选区 | 拒绝 | 拒绝 | 拒绝 | 以字节精确快照对比失败关闭 |

## 命令家族的特定规则

- 粗体、斜体和删除线：部分或混合命中一律拒绝；完整嵌套命中只切换目标层。单段软换行只在能验证为一个目标节点时包裹；包含空行的跨段选区返回 `AmbiguousSelection`，当前实现不提供“每个非空段分别包裹”。
- 行内代码：拒绝多行、纯空白和部分命中现有代码跨度。
- 围栏代码：以完整物理行处理，部分命中现有围栏时拒绝。
- 标题：完整行统一到指定级别；已全部为该级别时移除；Setext 规范化为 ATX。
- 引用：完整语义引用块添加或移除一层，包括懒续行。
- 列表：完整行统一为指定类型，保留缩进和任务勾选状态；已全部匹配时移除一层。
- 清除格式：仅处理选区内完整、语义有效的标记，不重新解释链接目标或代码内容。

## 插入命令

| 命令 | 空选区 | 完整选区 | 部分/混合/嵌套上下文 | 多行规则 |
| --- | --- | --- | --- | --- |
| 链接 | 插入可编辑的“链接文字”模板 | 普通文本作为标签；完整既有链接或完整标签只更新目标 | 与既有链接部分重叠拒绝；目标含控制字符、`<`/`>`/反斜线拒绝 | 标签候选必须能重新解析为一个精确链接，否则拒绝 |
| 图片 | 使用经验证的默认替代文本 | 普通单行文本作为替代文本；完整既有图片只更新目标 | 与链接/图片部分重叠、非安全目标或空替代文本拒绝 | 替代文本含换行拒绝 |
| 表格 | 插入 3×3 模板并选中首个表头 | 选中文本经管道符/换行转义后放入首个表头 | 光标或选区与已有表格重叠时拒绝 | 换行转为 `<br>`，表格作为完整块插入 |
| 分隔线 | 在光标处建立块边界并留下可编辑空行 | 不删除选中内容，在选区末端插入 | 候选不能解析为真实分隔线（如围栏内）时拒绝 | 只根据末端补齐块级空行，原选区字节不变 |
| 脚注 | 在光标处加唯一引用，文末加定义并选中占位文字 | 在选区末端加引用，不删除选中文本 | 围栏等无法产生精确引用+定义的上下文拒绝 | 保留选区；只在末端插入引用并重建冻结后缀 |
| 公式 | 插入 `$$` 块模板 | 单行包裹为行内公式；多行包裹为定界符独占行的块公式 | 与已有公式重叠、含 `$` 或候选无法精确重解析时拒绝 | 明确使用块公式，保留选中文本 |
| 图表 | 插入可编辑的基础 Mermaid 流程图模板 | 仅当选中文本可由已声明 Mermaid 子集完整解析时包裹 | 与已有围栏重叠或不支持图类/语法拒绝 | 以自适应反引号长度的完整 `mermaid` 围栏包裹 |

所有插入计划在 TextKit 提交时复用与格式命令相同的三重门禁：文档必须可编辑、不存在 IME marked text，且当前源文必须与计划快照字节精确一致。任一失败都是 no-op，不创建部分资源或撤销单元。
